# 엔진 번쩍임과 원거리 격침 섬광

2026-10-19. 사용자 요청은 두 가지다.
- 엔진·스러스터가 점화할 때 하얗게 번쩍이는 크기가 거리와 무관하게 비슷하고, 멀리 있는 미식별 적에게서도 보인다. 이를 고친다.
- 격침 폭발 섬광은 멀어서 작더라도 선명하게 보이게 한다.

## 1. 흰 번쩍임의 원인: 엔진 화염 셰이더의 NaN 화소

- 조사 순서
  - AI를 끄면(`--no-ai`) 번쩍임이 사라진다.
  - 그대로 두고 레이어별로 숨겨 봤다(탄도·병기·전투 효과·실드는 무관). 요격함 모델을 숨길 때만 사라졌다.
  - 모델 안에서는 엔진 화염·자세제어(RCS) 원뿔(`shaders/plume.gdshader`)을 숨길 때 사라졌다.
- 그런데 이 원뿔의 밝기를 0.09배로 줄여도 화면이 전혀 바뀌지 않았다. 일부 화소의 값이 NaN이었기 때문이다.
  - 진단색으로 확인한 결과, 일부 화소에서 시선 벡터(`VIEW`)가 NaN이었다. 원래 코드의 표면 법선(`NORMAL`)도 원뿔 끝처럼 길이가 0으로 보간되는 곳에서 정규화하면 NaN이 된다.
- 화면 공간 글로(블룸)는 NaN 화소를 흐림 단계마다 퍼뜨린다. 그래서 함선이 몇 픽셀이든 같은 크기(약 90px)의 흰 덩어리가 됐다.
  - 화면 크기가 거리와 무관하고, 멀리 있는 미식별 함선에서도 보인 것이 이 때문이다.
  - 자세제어 분사가 켜졌다 꺼질 때마다 깜빡였다.
- 수정(`shaders/plume.gdshader`)
  - 표면 법선 대신 원뿔 축과 직접 계산한 시선만 쓴다. 둘 다 0 길이를 피해 정규화한다.
  - 최종 밝기도 유한할 때만 낸다.
- 결과(`engine_before_after.jpg`): 요격 편대(약 1 km) 주변의 흰 덩어리가 없어지고, 실제 크기의 화염만 남았다.
  - 측정 영역의 밝은 화소(>200): 3,125 → 39개.
  - 가까운 자기 함선의 화염은 그대로다(`own_plume_before_after.jpg`).

## 2. 화면 크기에 따른 엔진 빛 감쇠 (`ShipView.EngineVisibility`)

- 화면 공간 글로는 밝은 화소를 고정된 화면 크기로 번지게 한다. 그래서 정상 화염이라도 아주 작게 보이는 함선은 상대적으로 크게 번쩍인다.
- 선체의 화면 길이가 24px 이상이면 그대로, 2px 이하면 0이 되도록 부드럽게 줄인다.
  - 적용 대상: 엔진 화염, 자세제어 분사, 반물질 격리 용기의 깜빡이는 빛.
  - 망원 시야에서는 함선이 크게 보이므로 다시 밝아진다.
- 팔레트(재질)는 함선마다 따로 만들어지므로 재질 파라미터 `visibility`로 넣었다.

## 3. 원거리 격침 섬광 (`CombatBurstBatch`, `shaders/combat_burst.gdshader`)

- 이전에는 격침 섬광을 화면에서 최소 85px로 키웠다. 그래서 먼 격침은 흐린 원판이 되고, 강한 발광(×4.5)이 블룸으로 번졌다.
  - 첫 전기 섬광은 0.18초 만에 사라져, 0.3초 무렵에는 아무것도 보이지 않았다.
- 이제 섬광의 실제 화면 크기가 40px보다 작으면 점광 형태로 그린다.
  - 64px 사각형 안에 약 3px의 흰 심, 1px 너비의 십자 광선, 얇게 퍼지는 고리를 그린다.
  - 작지만 또렷하다.
  - 대신 조금 더 오래 보인다. 전기 섬광 0.4초, 주 폭발 0.9초.
- 가까운 격침(실제 크기 40px 이상)은 기존 불덩이를 그대로 쓴다.
- 결과(`explosion_before_after.jpg`): 호위함 60 km, 전함 150 km. 0.1~1.2초 사이 모든 시점에서 점광이 선명하게 보인다.
  - 이전에는 0.3초와 1.1초에 아무것도 보이지 않았다.
- 미리보기에 거리 인자를 추가했다: `--fx-preview=far --fx-distance=<m> --fx-age=<s> --fx-ship=<id>`.
  - 이전 열은 main 빌드라서 이 인자가 없다. 기본 3,000 km에서 그렸지만, 이전 방식은 거리와 무관하게 85px라서 모양은 같다.

## 검증

- Godot 검사 통과
  - `combat-visual-test` 233개. 새로 넣은 검사는 다음과 같다.
    - 먼 격침은 점광, 가까운 격침은 불덩이.
    - 엔진 빛 감쇠 함수.
    - 몇 픽셀짜리 함선은 엔진 빛 0, 화면을 채운 함선은 1.
  - `environment-test` 204, `hud-readability-test` 873, `flow-test` 59, `model-test` 10,420.
- 연출 스틸(`cine-still salvo 2.0`) 렌더에 셰이더 오류가 없다.
- 시뮬레이션 코드는 바뀌지 않았다.

## 남은 것

- 다른 가산 셰이더(실드, 레이저 등)도 같은 NaN 위험이 있는지는 따로 점검하지 않았다.
- 실제 전투에서 느낌(멀리 격침 점광의 크기·지속)은 직접 플레이해 보고 조정할 수 있다.
