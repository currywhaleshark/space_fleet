# T4 순양함 실루엣 참고

`t4-cruisers.png`와 `prompt.json`은 이미지 생성 참고 원본이다. 왼쪽 위 나일, 오른쪽 위 스트라투스, 왼쪽 아래 멜라스, 오른쪽 아래 아르기레.

장갑 선수 / 분리된 방공 갑판 / 가는 선수와 외부 구조 / 긴 미사일 포드라는 주형태를 채택했다. 그림의 모든 포신·셀·구조물을 그대로 옮기지는 않는다. 실제 기본 무장은 네 함 모두 상·하부 연장 주포탑 2기, PD는 4/6/2/2기이며 미사일은 16/20/16/32발이다. 원래의 300/300/280/280m 길이 기준을 유지한다.

현재 공정은 기능 배치와 기본형이다. 최종 패널·볼트·수납 애니메이션·텍스처 제작은 뒤로 미룬다.
