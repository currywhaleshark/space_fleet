## 재작업

`tools/author-t4-cruiser-layouts.py` → Blender의 `tools/build-t4-cruiser-models.py -- --root <저장소> --render` → `tools/audit-cruiser-models.py -- --root <저장소> --tier4` → `tools/export-menu-art.ps1 -Models earth_gun_cruiser_t4,earth_air_defense_cruiser_t4,mars_gun_cruiser_t4,mars_missile_cruiser_t4` 순서.
