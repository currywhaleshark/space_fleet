# 격납고 UI 개편 (월오쉽·워썬더식 항구 화면)

2026-10-19. 사용자 결정과 목업(https://claude.ai/artifact/1S9UJf9L6mo4Gh43ynDhWS)에 따라 격납고를 장르에 익숙한 구조로 바꿨다. 새로 배우게 하기보다 익숙한 쪽이 낫다는 판단이다.

## 화면 구성 (`src/Game/HangarView.cs`)

- **위쪽 막대**
  - 메인으로, 격납고, 기술 연구, 전장 설정.
  - 가운데 큰 **출격** 버튼. 막혀 있으면 이유를 함께 표시한다.
  - 양 진영의 연구 점수, 편대 전력, 매칭 티어 범위.
- **왼쪽 · 내 편대**
  - 고른 함선이 기함인 편대의 슬롯.
  - 찬 슬롯에는 `⋯`(슬롯 메뉴)와 `×`(제거)가 있다. 기함 슬롯은 제거할 수 없다.
  - 우클릭과 `⋯`은 같은 메뉴를 연다: 함급 교체, 공유 프리셋 1/2/3, 개별 설정, 편대에서 제거.
  - 빈 슬롯은 `+ 함급 추가`이고, 누르면 함급 카드 창이 열린다.
    - 넣을 수 있는 함급이 앞에 온다.
    - 안 되는 함급도 흐리게 보여 주고 이유를 단다: 미해금, 호위함·순양함만, 같은 함종만, 기함보다 높은 티어.
    - 같은 함급을 여러 슬롯에 넣을 수 있다.
  - 빈 슬롯이 있으면 출격이 막히고, "기본 편성으로 채우기"를 제공한다.
- **가운데**
  - 함선 이름, 티어·역할·진영·슬롯.
  - 프리셋 선택 버튼: 프리셋 1 / 2 / 3 / 개별.
  - 3D 미리보기와 **도크 배경**.
  - 작은 아이콘 줄: 계통 6칸, 베이.
    - 기본형에서 바꾼 칸에는 청색 점이 찍힌다.
    - 마우스를 올리면 툴팁(칸, 장착 부품, 효과), 클릭하면 선택 목록이 열린다.
    - 목록에는 기존 부품 비교, 연구 비용, 장착 불가 이유가 그대로 나온다.
  - 적용 범위 안내: "공유 프리셋 1 · 같은 프리셋을 쓰는 모든 슬롯에 적용 (지금 n척)" 또는 "개별 설정 · 이 슬롯에만 적용".
- **오른쪽**: 성능 막대(전력, 추가 폐열, 가속, 실드)와 함선 상세.
- **아래 · 내 함선** 캐러셀
  - 함선은 구매가 아니라 해금이므로 "보유" 대신 "내 함선"이라 부른다.
  - 함종(전함·순양·호위·요격·정찰)과 진영으로 거른다.
  - ★ 즐겨찾기는 항상 앞에 정렬된다.
  - 카드를 끌어 다른 카드 위에 놓으면 그 자리로 옮겨진다. 즐겨찾기 묶음 안팎으로 끌면 즐겨찾기 여부도 따라간다.
  - ◌로 숨기고, "숨긴 함선 n"에서 다시 표시한다. 현재 기함은 숨길 수 없다.
- **Escape**: 열린 함급 카드 창이나 선택 목록을 먼저 닫고, 한 번 더 누르면 메인으로 간다.

## 장비: 기본은 공유, 필요하면 개별

- 슬롯은 기본적으로 함급의 **공유 프리셋 1~3** 중 하나를 쓴다. 같은 함급·프리셋 슬롯끼리 장비를 공유한다.
- **개별 설정**으로 바꾸면, 처음 한 번 현재 공유 프리셋을 복사해 그 슬롯만의 세팅을 만든다. 이후 변경은 그 슬롯에만 적용된다.
- 다시 공유 프리셋으로 돌아가도 개별 세팅은 보관되므로, 개별로 돌아오면 복원된다.
- 확인 창의 적용 대상 문구도 "같은 프리셋을 사용하는 함선에 함께 적용"과 "이 슬롯에만 적용"으로 구분한다.

## 저장 v4 (`src/Game/HangarProfile.cs`)

- `HangarSlot.Own`(개별 세팅)과 `Preset=3`(개별).
- 편대 슬롯에 `null`(빈 슬롯)을 허용한다. 기함 슬롯은 불가.
- 캐러셀 설정: `ShipOrder`, `Favorites`, `Hidden`.
- v1~v3 저장은 그대로 읽고, 다음 저장 때 v4로 기록한다. 보유, RP, 세팅은 유지된다.
- 검증
  - 빈 슬롯은 기본 편성원으로 채워 예산·규칙을 검증한다.
  - 개별 세팅에도 미연구 부품을 거부한다.
  - 목록 설정은 중복과 없는 함급을 거부한다.

## 도크 (`src/Game/HangarPreview.cs`)

- 함선 크기에 비례하는 궤도 정박지라서, 전함이든 요격함이든 같은 비율이 된다(`dock_bb_ic.jpg`).
  - 바닥 데크, 유도선, 정박등
  - 우현에 높은 계류탑 3기와 함체 직전까지 오는 계류 암, 위쪽 통로
  - 멀리 보이는 행성
- 기본 시점(좌현 앞쪽)에서 함선을 가리지 않도록, 가까운 쪽(좌현)에는 낮은 계류주만 둔다.
- 배경일 뿐이다. 충돌이 없고, 베이 표시는 함선 좌표를 그대로 쓴다.

## 검증

- `hangar-test`: 격납고 흐름 **83개** 통과. 새로 넣은 검사는 다음과 같다.
  - 빈 슬롯과 출격 차단
  - 기함 비우기 거부
  - 함급 카드: 가능·불가 이유, Escape로 닫기, 선택 시 공유 프리셋 1
  - 기본 편성 채우기
  - 개별 설정: 공유 프리셋에 영향 없음, 공유와 개별 사이 전환 후 복원
  - 슬롯 메뉴 항목과 기함 메뉴 제한
  - 즐겨찾기 우선, 드래그 이동, 숨김과 보유 유지, 현재 기함 숨김 거부
  - v4 왕복, v3 저장 읽기
  - 기존 흐름 검사는 계통 목록을 열고 확인하도록, Escape는 두 단계로 바꿨다.
- `progression-test` 36개, `flow-test` 51개, `match-flow-test` 43개 통과.
- 일부 로그에 `Invalid polygon data`가 남는다. 출처는 전투 HUD(`Hud.DrawSquadOrders`)이고, 이 변경과 무관하다.
- 시뮬레이션 코드(`src/Sim`)는 바꾸지 않아 SimChecks는 다시 돌리지 않았다.
