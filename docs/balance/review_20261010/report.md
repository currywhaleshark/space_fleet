## 비대칭 함대전의 함종별 기여

Earth-Mars와 Mars-Earth를 합산한다. 피해는 함선 1척당 누적 실드/모듈 피해의 평균이다. 생존은 최초 무력화 또는 격침까지이며, 끝까지 전투 가능하면 판정 시각에서 관측을 종료한다. 격침과 무력화 수는 종료 시점 상태이며 서로 겹치지 않는다.
