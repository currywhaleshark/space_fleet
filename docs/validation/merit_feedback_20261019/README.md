# 전과·리본 획득 연출

2026-10-19. 사용자 요청: 인게임에서 전과와 리본을 받아도 받았는지 바로 알 수 없으니 연출을 넣는다.

이전에는 우상단의 작은 글씨 두 줄과 좌측 카운터의 짧은 흰색 점멸이 전부였다. 월드 오브 워쉽처럼 조준점 가까이에서 즉시 보이도록 바꿨다.

## 연출 (`src/Game/MeritHud.cs`)

- **리본 팝업**: 조준점 아래, 무장 선택 줄 바로 위.
  - 개인 전과가 확정되는 순간 해당 리본이 1.3배로 튀어나오고 흰빛이 번쩍인 뒤 제자리로 돌아온다.
  - 같은 종류가 다시 나오면 새 리본을 만들지 않는다. 기존 리본의 숫자가 `×N`으로 올라가고 다시 튀어나온다.
  - 같은 순간에 여러 종류를 얻으면 0.08초 간격으로 차례로 튀어나온다(아직 기다리는 리본 뒤에 줄을 선다).
  - 최근 5종까지 보인다. 마지막 갱신 후 3.2초가 지나면 0.5초에 걸쳐 사라진다.
  - 색: 격침 금색, 무력화·계통 파괴 주황, 명중·관통·실드 붕괴 청색, 요격·보호 청록, 점령·방어 녹색, 정찰 보라.
  - 탐지·식별은 센서 집계라 팝업 없이 좌측 카운터에만 남는다.
- **주요 전과 배너**: 조준점 위 화면 중앙.
  - 격침·무력화·지원·어뢰 요격·점령·방어·기함 보호는 큰 배너로 나온다. 제목(예: "격침")과 표적 호출부호를 보여 준다.
  - 계통 파괴·실드 붕괴·프로브 격추는 한 줄짜리 작은 배너로 나온다.
  - 막대가 가운데에서 양옆으로 열리고(0.22초), 큰 제목은 크게 나타났다가 제자리 크기로 내려앉는다.
  - 4초 동안 보이고 마지막 0.6초에 사라진다. 동시에 최대 2개이며, 더 중요한 배너가 위에 놓인다.
  - 기존의 우선순위 대기열과 일반 명중 폭주 억제는 그대로 쓴다. 우상단 글씨 목록은 이 배너로 대체했다.
- **좌측 카운터**
  - 방금 얻은 종류는 해당 색으로 밝아지고, 옆에 `+n`이 1초 동안 떠오르며 사라진다.
- **공통**
  - 모든 시간은 화면 시간이다. 일시정지하면 멈추고, 전투 배속과 무관하다.
  - 전체 지도·메뉴·명단·도움말·관전 중에는 그리지 않는다.
  - 효과음은 기존 전과 효과음을 그대로 쓴다.

## 배치

- 1600×900 이상: 리본은 무장 선택 줄 위, 배너는 조준점에서 190px 위.
- 반물질 패널이 가운데에 오는 좁은 화면(요격함, 폭 1560 미만)
  - 리본은 그 패널 위로 올라간다.
  - 그래도 조준점과 너무 가까우면 배너 위로 옮긴다.
  - 요격 편대 상태 글씨와 겹치면 그보다 위로 올린다.
  - 1280×720, 글자 130%에서 확인했다(`ic_settled_720_text130.jpg`).
- 반물질 패널(`AntimatterBounds`)과 요격 편대 상태(`InterceptorStatusBounds`)는 실제 그린 영역을 매 프레임 기록해서 피한다.

## 검증

- `merit-test` **96개** 통과. 1600×900과 1280×720 모두, 실제 렌더러 사용. 새로 넣은 검사는 다음과 같다.
  - 배치: 리본이 화면 안에 있고, 조준점 주변 120×80과 무장 줄을 비운다.
  - 배치: 전과·편대·계기·반물질·요격 편대 패널과 겹치지 않는다.
  - 배치: 배너가 조준점 위에 있고 리본과 겹치지 않는다.
  - 위 배치 검사를 함선 2종 × 글자 100/130% × 등장 직후와 0.5초 뒤에 반복한다.
  - 연속 명중 10발이 리본 하나(×10)와 카운터 +10으로 합쳐진다.
  - 일시정지 중에는 리본 나이가 멈춘다.
  - 같은 종류를 다시 얻으면 같은 리본이 다시 튀어나온다.
  - 격침 리본이 오른쪽 끝에 붙고, 리본 수에 상한이 있다.
  - 동시에 얻은 리본은 차례로 튀어나온다.
  - 4.5초 뒤 리본·배너·카운터 표시가 모두 사라진다.
- 회귀: `hud-readability-test` 873개, `selection-hud-test` 142개, `flow-test` 59개, `match-flow-test` 43개 통과.
- 시뮬레이션(`src/Sim`)과 전과 집계는 바꾸지 않았다. 표시만 바뀐다.
- 화면
  - `bb_pop_start_1600.jpg`, `ic_pop_start_1600.jpg`: 전과 직후 첫 프레임. 리본이 튀어나오고 배너가 열리기 시작한다.
  - `bb_settled_1600.jpg`, `ic_settled_720_text130.jpg`: 0.5초 뒤.

## 남은 것

- 실제 전투에서의 체감(빈도, 시끄러움)은 사람이 직접 플레이해서 확인해야 한다.
- 리본 전용 효과음과 큰 격침 효과음은 따로 만들지 않았다.
