## 1차 — 공통 장애물 자료와 공간 질의

- `src/Sim/Obstacles.cs`: 고정 구/캡슐 묶음, 위치·자세·경계 구, 순서가 결정적인 첫 선분 충돌/근접 질의, OBB 접촉. 절대 위치를 float로 바꾸지 않고 double 회전·선분/상자 거리 계산을 사용한다. 빈 목록은 즉시 반환하며 기존 전투 루프는 아직 연결하지 않는다.
- `tests/SimChecks/ObstacleChecks.cs`: 180개 검사. 내부/외부 0 길이, 접선/스침, 양 끝 뚜껑과 축 평행 캡슐, 퇴화 캡슐, 삽입 순서와 무관한 첫 충돌, 실제 열린 고리, 회전·±1e12 m 좌표, OBB 접촉·탈출 법선 포함.
- 결과: 섬멸전 20/20, 기함전 20/20, 점령전 20/20 요약 JSON **바이트 일치**.
- 점령전 기준/1차 모두 Blue 8승·Red 12승·무승부 0, 판정 시각 중앙값 640.100초.
- 단독 Release 시드 1 `All/Tick`: 섬멸전 **241.874→234.520µs**, 점령전 **261.720→270.478µs**. 동시 전투 처리량은 성능 비교에 사용하지 않았다. 아직 장애물 질의가 전투에 연결되지 않아 단일 실행의 시간 변동을 알고리즘 효과로 해석하지 않는다.
