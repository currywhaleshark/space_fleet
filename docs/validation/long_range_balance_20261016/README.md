# 장거리 화력·전자전 균형 조정 — 2026-10-16

## 결과

지구 전함이 대응 사격 없이 격침되던 비대칭 함대전에서 **0/16척 발사 → 16/16척 발사**로 개선했다. 같은 시드·편성·진입 위치를 사용한 비교이며, 팀을 뒤집은 경우도 포함한다. 130km 단독 전함 결투에서도 지구 전함은 **0/8척 → 8/8척** 사격했다.

비대칭전 전함의 첫 사격은 조정 후 화성 평균 약 213.8초, 지구 약 226.9초다. **5초 간격 텔레메트리에서 처음 발사가 관측된 시간**이므로 실제 발사 시간보다 최대 약 5초 늦다. 화성의 선제 사격 기회는 유지되며, 지구가 대응하지 못한 채 일방적으로 맞는 상황은 시험한 모든 비대칭전에서 해소됐다.

## 원인과 수정

1. **잠금 획득·유지와 실제 포격 거리의 불일치.** 지구의 AI 주포 비행시간 제한은 8초(정지 기준 96km), 화성은 7.5초(135km)였다. 지구가 센서 잠금을 얻어도 주포 발사가 금지된 구간에서 먼저 피해를 입었다. 지구 10.5초·화성 7초로 조정해 정지 기준 발사 상한을 약 126km에 맞췄다. 실제 유효 거리는 상대 속도·잠금·사선·포탑 각도에 따라 달라진다. 물리 탄환의 최대 사거리를 동일하게 제한한 변경은 아니다.
2. **센서 전력을 되돌리는 AI의 허점.** 잠금을 얻은 뒤 적 ECM이 꺼지거나 아군이 미사일 방어에 들어가면 센서 핍을 낮춰 스스로 잠금을 잃었다. 약한 비방해 항적에도 센서 출력을 올리고, 높은 해제 문턱으로 유지한다. 방공과 추적 강화가 동시에 필요하면 `1/1/2/4/0`으로 배분해 무장 2·센서 4핍을 유지한다. 총 8핍이며 실드/추진 출력의 대가는 남는다. 충분히 강한 비방해 항적에서는 기본 배분으로 복귀한다.
3. **강한 ECM의 과도한 잠금 차단.** 실효 방해를 `raw / (1 + raw / 2)`로 변경했다. 자기 ECM과 호위함 방해 중 강한 값을 고른 후 한 번 적용한다. ECM 증가에 따른 효과는 계속 증가하지만 실효 방해는 2에 점근한다. 방해 전파의 노출, ECCM, 모듈 손상, 아군 데이터링크, 지형 차폐는 유지한다. 프로브 관측에도 같은 곡선을 쓰며, 프로브 단독 잠금 금지 상한 5.5는 유지한다.
4. **긴 비행시간에도 작은 모듈을 과도하게 정밀 조준.** 2초를 넘는 예상 비행시간에 `1.25 × (거리/탄속 − 2)² m`의 불확실성을 더하고 기존 관측 품질·전자전 배율을 적용한다. 짧은 비행시간의 요격 조준과 `sensorError:false`의 정확한 탄도 계산은 그대로다. 양측 대형함 AI는 예상 오차가 모듈의 가장 작은 반크기보다 크면 함체 중심으로 조준한다. 작은 센서보다 함체를 맞히기 쉬워지는 효과도 있으므로 주포 피해 수치를 함께 조정했다. 수동 부위 조준 자체를 금지하지는 않는다.

화성의 18km/s 탄속·5.2초 재장전·2기 연장포, 지구의 12km/s·3초·3기 연장포는 유지했다. 화성은 여전히 한 발의 에너지·관통력·탄속과 센서 성능이 우세하다. 지구의 함체 HP·장갑·실드나 모듈 위치를 늘려 버티게 한 수정은 아니다. 티어 변형 JSON도 생성기를 다시 실행해 갱신했다.

## 검증 조건과 자료

- 기준 버전은 이 작업 시작 시점의 작업 트리다. 이전 접근·강습 유지·AM 준비 수정과 새 블록아웃을 포함한다. Git HEAD가 아니다. 수정 전 BattleBatch 바이너리를 `shots/longrange-baseline-20261016/net8.0/`에 분리해 실행했다.
- `before/`, `after/`: 버전별 24척 함대전 24판 + 전함 결투 24판, 합계 **96판**. 함대전은 150km 시작, 지구 정찰 T3 편대와 화성 강습 T3 편대 사용. 비대칭 시드 1~4, 양팀 교환 및 진입 방향 반전. 대칭 시드 1~2 및 방향 반전. 결투는 20/70/130km × 시드 1~2 × 팀 교환 × 방향 반전. 최대 25분, 섬멸전, 심우주.
- 시드 1~2를 조정에 사용하고 3~4 및 팀 교환으로 결과를 확장했다. 모두 같은 지형 없는 배치이므로 일반 플레이 전체를 대표하지 않는다.
- `*.run.json`: 실행 명령과 당시 바이너리 SHA-256. 초기 `before/mixed`는 진단 실행에서 만든 기존 8판 결과를 재사용했다.
- `summary.json`: 승패·함종별 사격·명중·손상·생존 집계. `*.ships.csv`: 개함 통계. `*.telemetry.csv.gz`: 5초 간격 항적/사격 조건/전력/모듈 상태. 원본 CSV를 gzip 왕복 검증 후 압축했다.
- `curves.json`: 정지·정상 상태 48조건의 탐지/잠금/조준 오차. 호위 스크린 조건은 표적 옆 4km의 **화성 호위함**이며 팀과 설계 계통을 분리한 혼성 스크린도 포함한다. 정지 시험의 센서 곡선을 이동·발열·미사일 발사 중 전투 사거리로 해석하면 안 된다.
- `candidate1`~`candidate6`, `candidate5-matrix`: 중간 조정 자료. 최종 결과는 `after/`만 사용한다. `candidate5-matrix`의 실행 기록 경로는 당시 사용한 `after/`이며 결과 보존을 위해 폴더 이름을 바꿨다.
- 자동검사·빌드·모델 보존 결과는 `checks.json`, `simchecks-final.log`, `*-build.log`에 기록한다. 신규 검사에는 장거리 오차, 1e12 좌표, 관측 스냅샷 독립성, 두 진영 부위 조준 제한, ECM 한계효용/호위 비중첩, 방공 중 추적 전력, 비방해 약한 잠금의 유지, 130km 대응 사격을 포함했다.
- 전체 **5,607,904개 검사, 신규 회귀 78개 통과**. 게임/도구/검사 빌드 경고·오류 0. 이전 블록아웃 기록과 비교한 Blender·GLB·배치 파일 22개가 동일하다. 센서 순회 참조 검사 수는 탐지 결과 변화에 따라 이전보다 136개 늘었다.
- 기존 강습 검사는 전함이 30km 표적을 먼저 격침해 실패하는 것을 확인해 관측/기준점 전함의 AI 사격을 비활성화했다. 편대 자신의 공격·피해·제공 전환 검사는 유지했다. 초기 데이터 추출 때 고정해 둔 AI 상수 검사는 이번에 의도적으로 바꾼 수치로 갱신했다.

## 남은 한계

- 비대칭전 지구 승률은 6/16(37.5%)이며 팀을 바꾸면 5/8 대 1/8로 갈린다. 화성 대칭전도 4판 모두 Red 승리다. 표본·배치·호출부호별 조준 잡음·치명타의 영향을 포함하므로 균형 완성이나 팀 공정성 입증으로 해석하지 않는다.
- 결투 20km에서는 화성 8/8승, 70km에서는 지구 7/8승, 130km에서는 지구 6/8승이다. 고립된 지구 전함은 근거리 첫 센서 저격 후 관측 링크를 받을 아군이 없어 여전히 취약하다. 장거리 대응 사격 문제를 고친 것과 모든 거리에서 역할에 맞는 승률을 달성한 것은 구분한다.
- 함체 중심 조준으로 바뀐 화성 전함의 비대칭전 주포 명중률은 약 98%다. 작은 모듈 저격 빈도는 줄었지만 큰 전함을 맞히는 정확도까지 낮아진 결과는 아니다. 관측 오차·기동·부위별 관통의 추가 조정 후보로 남긴다.
- 모델·모듈 배치, 반물질탄·근접방어 성능은 이번 작업에서 바꾸지 않았다. 다수 편대 10:10 매칭, 소행성 전장, 플레이어 직접 조작은 이번 비교 행렬에 포함하지 않았다. 성능 측정도 아니며 병렬 실행의 벽시계 시간을 FPS 개선 근거로 쓰지 않는다.
- 배포 실행파일·커밋·푸시는 별도다.
