# 레이저 빔 시각 효과 — 일정한 두께와 날카로운 심

2026-10-19. 사용자 요청: 레이저 두께가 들쭉날쭉하고 날카로움이 부족하다.

## 원인

- **심**: 빔 심에 원형 플레어용 발광 셰이더를 썼다. 긴 사각형에 원형 감쇠를 적용하니, 가운데가 굵고 밝고 양끝이 가늘어지는 렌즈 모양이 됐다.
- **후광**: 탄환 꼬리용 셰이더를 썼다. 그래서 빔 길이 방향으로 한쪽 끝부터 흐려졌다.
- **폭**: 빔 중간 지점 거리 기준의 월드 단위로 정했다. 원근 때문에 사수 쪽은 굵고 표적 쪽은 가는 쐐기 모양이 됐고, 카메라 거리에 따라 폭이 출렁였다.

## 변경

- `shaders/laser_beam.gdshader`
  - 정점 단계에서 빔 중심선을 화면에 투영한 뒤, 그 수직 방향으로 **픽셀 단위 폭**을 펼친다. 기준은 1080p이고 해상도에 비례한다.
  - 총구에서 수 km 떨어진 표적까지 두께가 같다.
  - 심: 반폭 1.4 px의 흰색. 가장자리는 ±0.6 px로 안티에일리어싱해 끊는다.
  - 후광: 반폭 7 px의 진영 색(지구 청색, 화성 주황).
  - 채널링 집속(`FocusFraction`)이 쌓이면 심이 최대 25%, 후광이 최대 35% 넓어지고 후광이 밝아진다.
  - 중심선까지 거리는 `(거리 × w, w)` 쌍으로 넘겨 화면 기준으로 선형 보간한다. 일반 원근 보정 보간을 쓰면, 멀어지는 빔에서 사각형의 두 삼각형이 값을 비틀어 한쪽 끝이 넓어 보였다.
- `CombatFx.Beam`
  - 빔 사각형을 끝점 사이에 놓는다.
  - 카메라 근평면 뒤나 원평면 너머로 나간 끝점은 그 평면에서 잘라 둔다. 셰이더가 화면 투영에 쓰는 w가 0 이하가 되지 않게 하기 위해서다.
- `BallisticsView`: 레이저마다 사각형 두 장(후광+심) 대신 빔 한 장을 그린다. 총구·명중 섬광은 그대로 둔다.
- `LaserGameChecks`: `--laser-view=chase`로 사수 함미 뒤에서 빔이 멀어지는 시점을 고를 수 있다.
