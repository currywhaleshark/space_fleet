# 방공순양함: 다른 아군 방어 + 대기 레이저 선행 조준 (2026-10-25)

## 계기

실제 티어 매칭(T4 방공순양함 편대, 시드 1)에서 B09-2가 330초 동안 레이저를 한 발도 쏘지 않았다(`B09-2_seed1_before.txt`).

- 사거리 안을 지나는 미사일 6~9발은 다른 아군(B04-1, B02-3)을 노렸다.
  - 방공 포대는 자함·기함(anchor)을 6.5 km 이내로 지나가는 미사일만 표적으로 삼아 무시했다.
- 88초에 미사일이 2.8 km 옆 기함 B09-1로 표적을 바꾸고, 약 7 km/s로 접근했다.
  - 남은 시간은 약 5초였다.
- 접근 방향은 후방 상부였다.
  - 상부 레이저는 전방을 향해 대기하다 약 95°를 돌았다. 오차 0.08°(허용 0.03°)에서 미사일이 선회 한계 165°를 넘어갔다.
  - 하부 레이저는 위쪽을 볼 수 없었다.
- 대응 미사일 20발이 준비돼 있었지만, 요격 해가 있는 순간이 23회 중 2회뿐이라 발사하지 않았다.

## 변경 (`src/Sim/CruiserDefenseBattery.cs`)

1. **다른 아군 방어**
   - 사거리 안의 식별된 미사일이 활성 아군 아무에게나 6.5 km 이내로 접근하면 표적 후보가 된다(같은 `Threatens` 판정).
   - 자함·기함 위협이 먼저이고, 다른 아군 위협은 도착 시각에 8초를 더해 순위를 매긴다.
   - 아군별 도착 시각은 진영·틱마다 한 번, 관측된 미사일(`_aiThreats`)로만 계산한다. 실제 미사일의 위치·표적은 읽지 않는다.
2. **대기 레이저 선행 조준**
   - 이번 틱에 표적이 없는 포탑은 12초 안에 자함에 가장 먼저 다가오는 관측 미사일 쪽으로 돌린다.
   - 잠금 전이거나 아직 위협이 아니어도 적용된다. 단, 포각 밖이면 제외한다.
   - 이 포탑은 방어용으로 잡아 두어, 함선 포격이 다른 데로 돌리지 않는다. 여기서 발사하지는 않는다.
- 대응 미사일(탄수 제한) 선택은 기존대로 자함·기함 위협만 본다.
- `PrepareAIThreats`는 AI가 없는 세계에서도 관측 미사일 목록을 채운다. 플레이어 방공순양함의 자유 사격 포대가 같은 목록을 쓰기 때문이다. 공간 색인은 기존대로 AI가 있을 때만 만든다.
