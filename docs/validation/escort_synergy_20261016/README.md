# 전함 단독·호위함 지원 비교 — 2026-10-16

지구의 호위함 지원 시너지는 실제 전투에서 작동한다. 다만 **20~70km 조합전은 지구, 130km 장거리전은 화성으로 승패가 지나치게 갈린다.** 사용자 설계 방향인 ‘전함 단독은 화성 소폭 우세, 조합으로 지구가 상쇄’에 접근하는 요소는 있지만, 아직 완성된 균형은 아니다. 이번 작업은 측정 도구·보고서만 추가했으며 실제 함선 수치, 전투 AI, 센서망, 모델은 변경하지 않았다.

- 일반 심우주, 60Hz, 실제 피해·응급복구·탄약·미사일·PD·드론·센서 제한 유지. 기존 섬멸전 승리 조건/최대 25분 적용. 전함 상실 후 남은 전력이 50% 이하이면 종료하므로, 1+2 전투는 호위함 두 척이 살아 있어도 끝날 수 있다.

## 주 비교

표는 지구 승 : 화성 승 : 무승부. 거리는 시작 거리이며 전투 중 움직인다.

| 시작 거리 | 전함 단독 | 양측 전함 1+호위함 2 | 지구 승률 변화 |
|---|---:|---:|---:|
| 20km | 16 : 48 : 0 | 60 : 4 : 0 | 25.0% → 93.8% |
| 70km | 41 : 23 : 0 | 64 : 0 : 0 | 64.1% → 100% |
| 130km | 11 : 52 : 1 | 7 : 57 : 0 | 17.2% → 10.9% |

같은 시드·팀·배치를 짝지으면 20km는 화성 승→지구 승 46건, 반대 2건이다. 70km는 화성 승 23건이 모두 지구 승으로 바뀌었다. 130km는 지구 승→화성 승 9건, 화성 승→지구 승 4건, 무승부→지구 승 1건이다. 거리별 64판을 균등 합산한 단독전 화성 승률은 64.1%, 조합전 지구 승률은 68.2%지만 실제 매칭의 거리 분포와 같지 않으므로 이 합계만으로 ‘소폭 우세’를 판단하지 않는다.

| 시작 거리 | 지구만 호위함 2척 | 화성만 호위함 2척 |
|---|---:|---:|
| 20km | 64 : 0 : 0 | 17 : 47 : 0 |
| 70km | 64 : 0 : 0 | 25 : 39 : 0 |
| 130km | 8 : 56 : 0 | 6 : 58 : 0 |

70km에서 화성만 지원하면 화성은 단독 23승→39승으로 개선한다. 양측에 지원을 붙이면 지구의 센서 손실 보완 효과가 더 크게 나타난다. 130km에서는 지구만 지원을 붙여도 화성을 상대로 우세해지지 않는다.

## 지원 효과의 근거

| 시작 거리 | 지구 전함 발사 합계, 단독→조합 | 조합에서 자체 센서 기능 상실 후 아군 관측으로 발사 | 지구 호위함의 아군 총 모듈 피해 기여 |
|---|---:|---:|---:|
| 20km | 430 → 944발 | 39/64척, 258발 | 41.3% |
| 70km | 422 → 1,168발 | 61/64척, 634발 | 4.5% |
| 130km | 994 → 618발 | 0발 | 0% |

- 20km: 호위함의 추가 포격과 센서 관측 분산이 함께 기여한다. 단독 지구 전함 64척 모두 가동 중 센서 기능이 소실됐다. 조합에서도 62척이 소실됐지만 일부가 호위함 정보로 추가 사격했다.
- **70km: 지구 호위함 128척의 주포 발사는 전부 0발이다.** 호위함의 미사일 피해도 아군 총 모듈 피해의 약 4.5%다. 그럼에도 지구 전함의 발사량은 약 2.77배, 모듈 피해 합계는 35,196→70,367이다. 지구 전함의 634발은 자체 센서 기능 2% 이하에서 아군의 신선한 관측을 사용한 직접적인 링크 사격 증거다. 무기·전자전·표적 분산을 완전히 제거한 인과 실험은 아니므로 승률 상승 전부를 링크 하나에 배분하지는 않는다.
- 화성도 70km 조합전 전함 발사 698발 중 630발이 아군 관측을 사용한다. 양쪽 모두 링크를 활용하며, 지구는 센서 저격으로 잃었던 사격 능력을 복구하는 이득이 특히 크다.
- 조합에서 살아 있는 호위함의 전함과 평균 거리는 지구 약 1.8~2.0km, 화성 약 3.0~4.1km다. 진영별 대형 차이는 실제 운용 그대로 유지했다.

### 장거리 무사격 8판

130km 단독전 지구 전함은 64/64척 사격했지만, 조합전은 56/64척만 사격했다. 이 8판의 패턴은 초기 잠금과 주포 발사 가능 시간이 어긋나고, 전자전 지원으로 잠금을 잃은 뒤 격침/무력화되는 것이다. 조합에서 발사한 지구 전함의 첫 발사 평균은 48.7초, 화성은 32.1초다. 지구 평균은 발사한 56척만 대상으로 하며 8척 무사격을 숨겨 포함하지 않는다.

대표 `s12-d130000-ebFalse-mTrue`:

- 호위함 없음: 5초 지구 추적 SNR 9.595, 15초 6.481. 잠금 유지 문턱 6.4보다 높아 잠금을 유지했고, 25초까지 4발 발사.
- 양측 호위함 2: 5초 SNR 8.476, 15초 5.887로 잠금 해제. 이후 약 6대로 올라가도 재획득 문턱 8에 미달. 초기 잠금 때는 예상 탄 비행시간 10.7초로 AI 제한 10.5초 밖이었다.
- 같은 조합전에서 34.1초 지구 우현 전력 버스 손실, 42.6초 격침. 센서 모듈이 먼저 저격당한 근거리 패턴과 다르다.
- 화성만 호위함을 붙인 대조군도 같은 초기 잠금 상실을 보인다. 이는 화성 호위함 ECM 차폐가 문턱 근처에서 유효한 지원임을 보여준다. 지구 호위함은 이 거리에서 더 좋은 관측을 제공하지 못한다.

8개 무사격 사례: `s11/Blue/미러`, `s12/Red/미러`, `s15/Red/미러`, `s16/Red/미러`, `s3/Red/미러`, `s4/Red/미러`, `s7/Red/미러`, `s8/Red/미러`의 130km 양측 지원 조건. 원본 파일명은 `results.json.gz`의 Case.Id와 일치한다.

### 방공·생존·편차의 해석

- 조합전 미사일 격추 합계는 20/70/130km에서 지구 11/12/4발, 화성 17/5/0발이다. 포격으로 전함이 먼저 상실되는 짧은 시험이 많아 이번 결과만으로 지구 방공 우위를 입증하지는 못했다. 대규모 함대의 미사일 물량·요격함 접근 시험이 별도로 필요하다.
- 조합전 종료 시 지구 전함 격침은 4/0/55척, 화성은 58/60/7척이다. 격침 외 무력화로 끝난 경우도 있어 승수와 정확히 같지 않다. 생존 함선은 승리 순간 측정이 끝나는 중도절단 자료다. 빨리 이긴 조합의 평균 활동시간이 짧다는 이유로 생존성이 낮다고 해석하지 않는다.
- 70km 단독전은 지구 Blue일 때 25/32승, Red일 때 16/32승이다. 130km 조합전은 지구 Blue 6/32승, Red 1/32승이다. 호출부호 기반 관측 오차·피해 추첨과 초기 자세/공간 위치에 대한 민감도는 남아 있다.
- 모든 지원함 추가는 사격 순번과 표적 선정도 바꾸므로, 같은 시드라도 피해 추첨 결과가 완전히 같게 고정되지는 않는다. 팀/공간 교환과 여러 위치 시드를 같이 사용한 이유다.

4. 동시에 20~70km의 조합 승률이 과도하게 쏠리지 않도록 첫 일제사격, 핵심 모듈 노출/피해, 화성의 거리 유지 운용을 살핀다. 화력 전체를 일괄 올리는 조정보다 실제 패배 경로를 대상으로 한다.
5. 10:10 편대, 미사일/요격함 포함 편성, 소행성 환경, 직접 조종으로 확대한다. 이 소규모 시험으로 최종 매칭 균형을 선언하지 않는다.
