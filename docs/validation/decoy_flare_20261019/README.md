# 디코이: 거리와 무관한 크기 → 밝은 노란 섬광

2026-10-19. 사용자 지적: 엔진 번쩍임(NaN)과 비슷하게 디코이 크기도 이상하다. 모양도 노란 공이 아니라 미사일이 현혹될 만한 밝은 노란 섬광으로.

## 원인

- 디코이는 구(sphere)에 흰빛 발광 8배 재질을 입혀 그렸다.
- 크기가 `max(2 m, 카메라 거리 × 0.0025) × (0.6 + 남은 수명)`이었다.
  - 거리에 비례해 키우므로 화면 크기가 거리와 무관하게 늘 약 3~4 px였다.
  - 시야각을 고려하지 않아 망원(×4)에서는 그대로 4배로 부풀었다.
- 강한 발광 때문에 화면 공간 글로가 덩어리로 번졌다.
- NaN 문제는 아니었다. 셰이더에 정규화 같은 위험 연산이 없다.

## 변경

- `shaders/decoy_flare.gdshader`: 카메라를 향한 사각형에 그리는 섬광.
  - 흰 심, 노란 광륜, 짧은 십자 광선.
  - 마그네슘 조명탄처럼 불규칙하게 깜빡인다.
  - 남은 수명만큼 밝고, 수명 끝 15%에서 꺼진다.
- `OrdnanceView`
  - 크기: 실제 광륜 크기(지름 40 m × (0.6 + 0.4 × 남은 수명)).
  - 화면 크기 하한: 24 px. 3 km 밖부터 거리에 반비례해 줄인다(최소 25%).
  - 화면 크기 계산은 시야각을 반영한다(`CombatFx.Flare`). 그래서 망원에서도 실제 비율로 보인다.
  - 지운 병기 노드는 `QueueFree` 전에 숨긴다. 같은 프레임 안에서 사라진 노드가 보이던 틈을 막는다.
- 시뮬레이션(디코이 신호·수명·유인)은 바뀌지 않았다.

## 검증

- `combat-visual-test` 237개 통과. 새로 넣은 검사는 다음과 같다.
  - 실제 디코이 사출
  - 가까이서 실제 광륜 크기 유지
  - 150 km 밖에서 화면 하한 이하로 줄어듦
  - 다 탄 디코이 제거
- 회귀: `flow-test` 59, `match-flow-test` 43, `weapon-input-test` 309 통과.
- 화면(`before_after.jpg`): 미사일 훈련(12 km)에서 자동 디코이 사출 1.5초 뒤.
  - 이전: 흐린 흰 점.
  - 이후: 십자 광선이 있는 밝은 노란 섬광.
