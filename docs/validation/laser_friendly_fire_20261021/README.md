# 자동 레이저의 아군 실드 피격 수정

2026-10-21. 사거리·위력·연사력·발열·센서·ECM·함체 데이터는 그대로 유지한다. 레이저가 실제로 맞힐 아군을 보호하는 사선 검사만 수정했다.

## 원인과 수정

기존 `FriendlyInLine`은 선체만 검사했지만 실제 레이저는 선체 바깥의 실드와 충돌했다. 또한 AI의 발사 판단 뒤 240Hz 하위 틱에서 함선과 포탑이 움직이고, 최종 레이저 조사는 그 이후에 처리되므로 사전 검사만으로는 충분하지 않았다.

- 자동 대함 사격·방공순양함 배터리·요격함 AI의 레이저 사전 사선 검사는 `FirstDefenseHitAtPose`를 사용해 현재 실드와 선체를 함께 확인한다. 실드가 꺼지면 남아 있는 선체만 차단한다.
- 발사 요청에 자동사격 여부를 전달한다. 실제 레이저 충돌 계산에서 가장 가까운 대상이 살아 있는 아군이면 조사와 피해·발사 통계·피격 효과를 중단한다. 이미 계산한 충돌 결과를 재사용하므로 별도의 전장 전체 광선 탐색을 추가하지 않는다.
- 표적 뒤 아군까지 무조건 사격을 막는 방식이 아니다. 미사일이나 적함이 실제로 먼저 광선을 흡수하면 그 명중은 정상 처리한다. 빗나간 광선이 아군으로 향하거나 앞의 미사일이 제거되면 다음 조사를 중단한다.
- 아군을 광선에서 무시하거나 관통시키지 않는다. 선체·실드의 물리 충돌을 보존하고 자동 발사를 멈춘다. 아군이 사선을 벗어나면 다음 정상 요청으로 다시 사격한다.
- 기존 직접 수동사격의 아군 피격 규칙과 비레이저 무장의 사선 판정은 유지했다. 수동/자동 요청 전환과 무장 초기화에서도 상태가 남지 않는지 검사했다.

## 문제 파형 재검증

이전 `interception_20261021/stress-diagnostics.json`과 같은 T5 방공함 1척, 보호 전함 1척, 기준 정면 32km·네 방향 48발 배치를 사용했다. 방향·속도·기본 무장·시드 모두 동일하다.

시드 1, 2,000m/s, ECM 없음: **아군 실드에 맞은 레이저 조사 17→0회**, 미사일 격추 17발은 동일했다.

| 속도 | ECM | 반복 | 미사일 | 아군 레이저 피격 | 미사일 요격 |
|---:|---|---:|---:|---:|---:|
| 2,000m/s | 없음 | 8회 | 384발 | 0회 | 142발 |
| 2,000m/s | 전방 지원함 1척 | 8회 | 384발 | 0회 | 140발 |
| 6,000m/s | 없음 | 8회 | 384발 | 0회 | 96발 |
| 6,000m/s | 전방 지원함 1척 | 8회 | 384발 | 0회 | 88발 |

총 **32회·1,536발에서 아군 레이저 피격 0회**. 매 틱 실제 레이저 펄스의 피격 대상을 검사했고, 격추 공로와 미사일 체력·명중·잔존 합계도 확인했다. 원본은 `waves-after.json`이다.

일부 시드의 요격 수는 아군 사선에서 사격을 보류하거나 다른 표적을 고르는 과정이 달라져 변했다. 이는 안전한 사격 선택으로 인한 전투 결과 변화이며, 무기 능력치를 조정한 것은 아니다. 기존 비교 파일은 수정 전 증거로 보존했다.

## 검사

- 신규 66개: 선체를 비껴 실드만 맞는 경로, 1e12 좌표, 자동 대함 사격, 실드 붕괴/복구, 아군 이탈 후 재사격, 발사 요청 후 아군이 실제로 이동해 사선에 진입, 미사일 명중/빗나감/제거 직후, 아군보다 앞의 적함·지형, 수동 모드 전환, 32개 전투 파형.
- 기존 레이저 226개, 미사일 관측·사거리 35개, 포탑 71개, 추적 4개, 사격통제 26개, PD 추적 272개, 방공 레이저 37개 통과. 신규 포함 **737개 검사 통과**.
- 게임 C# 빌드 경고/오류 0. SimChecks 빌드는 기존 nullable 경고 6개, 오류 0.
- Godot `--headless --laser-test`의 레이저 표시 노드·음향 상태·장비 연결 17개 통과. 이는 엔진 실행 검사이며 픽셀 화면의 육안 검수는 아니다. 제한 환경의 최초 .NET 로딩 실패 후 일반 로컬 환경에서 정상 완료했다.
- 전투·무기 데이터 파일 변경 없음. 이번 수정에서 전체 장시간 승률 시험이나 실행파일 배포는 하지 않았다.
