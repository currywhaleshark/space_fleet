# HUD v4 시안 외형 맞춤 검증

기준: `HUD_Prototype_v4.html`(Space_Fleet_HUD_Targeting_Handoff_v4) 화면 계층. 작업일 2026-10-23, 기준 커밋 `f93fcdc`.

## 사용자 결정

- 레이더는 기존 3D 구형 유지(시안의 2D 레이더 미적용).
- 그 외는 시안에 최대한 맞춤. 접촉 단계는 원형 대신 "레이더에 잡힌 흐릿한 표적" 표현, 단 함형·길이·자세 비노출.

## 변경

- `HudStyle`: 시안 색 토큰(ink/cyan/mint/amber/red), 모노 글꼴(Cascadia → Consolas, 한글은 맑은 고딕 대체), 얇은 테두리 패널, 시안 SVG 기호를 런타임 래스터화한 선 아이콘. 기존 `Hud` 색 상수를 이 팔레트로 교체.
- 표적창(`TargetViewport`): 302px 패널, 이름·거리·3칸 센서 등급, 관측 화면(배경 그라데이션·주사선·눈금), `LOCKED / EXTERNAL` 등 상태와 관측 면(함수/함미/좌현/우현 · 상부/하부/측면), 하단 안내, `◇ 선체 [Y]` 줄, 관측 실드 막대(구조는 비관측이라 빗금 "—"). 식별 이상은 면 음영 홀로그램 셰이더(`shaders/target_hologram.gdshader`), 2배 해상도·MSAA 2x, 10Hz 갱신 유지.
- 접촉 신호: 모든 함급에 같은 번진 레이더 반향 + 수신 잡음. 퍼짐은 위치 오차로만 변하고 함형·길이·자세 정보 없음. 하단에 `±오차`.
- 하단 1–7 바: 81×72 칸, 아이콘, 선택 무장 강조, 1–3/4–7 구분선, READY/쿨다운/가동 표시와 진행선. 상세 모드는 이름 병기.
- 기동 계기: 큰 속도 숫자+속도/추력 띠, 기수·편류 원, G 원형 게이지, 상태 칩(보조/방식/부스트/ECM/교리·사격보조/배속/미사일 경보).
- 자함(호출부호·복구 키·실드/구조 막대·추진/무장/센서/냉각/발전 계통), 편대(이름·구성원 점·생존 수·함대 태세 기호), 지원(드론/보조 포탑), 전력(F, 5채널 핍, 열 줄) 패널을 시안 위치에 상시 배치.
- 상단 점수 줄(숫자·막대·거점 원·시계), 레이더 아래 범위 표시와 아이콘형 전과 줄, 전과 리본을 시안 토스트 형식으로.
- 포탑: 포탑별 실제 방향 표식(모서리 괄호+상태 기호), 선행점에서 표식으로 이어지는 안내선, 선행점 아래 번호 칩(정렬/선회·장전/포각 밖/사선 가림/파괴 ×/전력·냉각 불능). 화면 폭에 퍼지던 상태 글자 줄 제거.
- 상세(I): 기존 대형 패널 대신 계통·응급복구 드롭, 계통/전력 수치 표기, 지원 패널 추가 줄, 사격통제 패널, 요격 편대 상태.
- 화면 하단·좌우 가장자리 음영(시안보다 약하게).

- 화면 속 적 표식(괄호·라벨)과 조종 방식별 중앙 조준선은 기존 형태 유지(라벨 배치 검사 873개 보존 목적).

- 80척 혼성전 FPS·HUD 비용은 이번에 다시 재지 않았다.
- 배포 EXE 미갱신, 커밋 안 함.
