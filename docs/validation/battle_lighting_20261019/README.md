# 전투 조명: 해를 등진 함선도 형태가 읽히게

2026-10-19. 사용자 결정: 작업등을 다는 대신 조명 조정을 먼저 시험한다.

## 원인

- 기존 조명은 태양(2.0)만 강했다. 그늘을 채우는 빛은 약했다: 테두리광 0.35, 행성 반사광 0.18, 주변광 0.3.
  - 그래서 해를 등진 면은 거의 검게 남았다.
- 해를 받는 면도 어두웠다(`gallery_before.jpg`의 lit 열).
  - 선체 재질의 금속성이 0.5~0.6이었다.
  - 금속면은 확산광 대신 주변을 반사하는데, 반사할 것이 검은 별하늘뿐이다. 그래서 정면으로 해를 받아도 짙은 회갈색으로 보였다.

## 변경 (`src/View/BattleLook.cs`, 선체 재질)

| 항목 | 이전 | 이후 |
|---|---|---|
| 태양 | 2.0 | 2.4 |
| 주변광 | 0.3 (0.24, 0.28, 0.36) | 0.55 (0.26, 0.31, 0.4) |
| 테두리광(해 반대쪽, 차가운 색) | 0.35 | 0.9 |
| 행성 반사광(아래 왼편) | 0.18 | 0.5 |
| 시점 보조광 (새로 추가) | 없음 | 0.35, 카메라보다 약 20° 위에서 보는 방향으로 |
| 선체 금속성 | 0.5~0.6 | × 0.45 (`BattleLook.HullMetalScale`) |

- 테두리광, 행성 반사광, 시점 보조광은 함선 층에만 비춘다. 소행성은 기존처럼 해와 국소광만 받는다.
- 시점 보조광은 매 프레임 카메라를 따라간다(`BattleLook.AimViewFill`).
  - 적용 위치: 전투 화면(`ScaleTest`), 함선 검토 장면(`ModelGallery`).
  - 어느 쪽에서 보든 보이는 면의 형태가 드러난다.
  - 약하게 두고 위에서 비춰서 음영의 방향감은 남긴다.
- 금속성 배율은 두 경로에 모두 적용했다: 가져온 모델의 `hull_panels` 셰이더, 구성형 선체의 `Palette`.
  - 흑연색 기본색(시안 기준)은 그대로다.
- 연출 영상(CineDirector)은 자체 조명을 써서 이번 변경에서 빠졌다. 선체 금속성 변화는 영상에도 적용된다.

## 비교

- 함선 검토 장면: 전함, 화성 전함, 호위함, 요격함 × 4시점.
  - 시점: 해를 정면으로 받는 lit, 기존 대표 구도 hero(해 반대편 위), 해 반대편 옆 side, 아래에서 올려다보는 below.
  - `gallery_before.jpg`: 이전.
  - `gallery_v1.jpg`: 빛만 조정. 그늘 쪽이 좋아졌지만 해 받는 면은 여전히 어둡다.
  - `gallery_v2.jpg`: 빛 + 금속성 + 태양. 채택한 안이다.
- 함선 영역 평균 밝기(0~255, 4척 평균)

  | 시점 | 이전 | v1 | v2 |
  |---|---|---|---|
  | lit | 30.8 | 33.5 | 47.1 |
  | hero | 47.8 | 51.8 | 54.7 |
  | side | 24.6 | 33.5 | 38.0 |

  - below는 선체가 화면 절반을 덮어 배경 추정이 틀어지므로 수치를 내지 않았다. 눈으로는 이전보다 판 구조가 뚜렷하다.
- 실제 전투 화면(`ingame_crop.jpg`, `ingame_full.jpg`)
  - 기본 시점에서 내 전함 후미와 오른편 호위함의 구조가 더 읽힌다.
  - 뒤돌아본 역광 시점에서 호위함 함수가 더 읽힌다.

## 남은 것

- 1 km 거리의 요격함처럼 화면에서 아주 작은 함선은 여전히 잘 보이지 않는다. 표지(HUD 괄호)가 그 역할을 한다.
- 더 밝게 할 여지가 있다. 시점 보조광 0.35 → 0.5, 금속성 0.45 → 0.35처럼 올릴 수 있다. 다만 지나치면 음영이 평평해진다.
- 그래도 역광이 약하면 작업등(진영 색 표시등, 함교 창 같은 발광 지점)을 보조로 더할 수 있다.
