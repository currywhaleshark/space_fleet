# T5 전 함급 독립 기본형 — 2026-10-17

사용자 요청: 앞선 T1·T3·T4 기본형 작업에 이어 남은 함급도 제작. 이미지 참고안 → 독립 Blender 원본/GLB → 장비·피해 좌표 → 실제 Godot 확인 → Windows 배포 순서다. 10개 T5 hull을 분리해 **전체 34함급 / 34모델**을 채웠다.

기존 24모델의 Blender/GLB/초상화와 원본 6함선 데이터는 보존했다. 주포·PD 포대 수, 발사속도/탄수/탄속/위력, 장갑 두께, 모듈 크기/HP, 센서/전자전, 가속/질량 등 성능 수치는 바꾸지 않았다. 새 외피 구획은 기존 구획의 장갑 값을 명시적으로 상속한다. 달라진 실루엣과 모듈 배치에 따른 피탄 면적·사각은 후속 실전 조정 대상이다.

포탑 피벗/트러니언/포구는 유지했다. 움직이는 연장 주포와 PD는 검증된 기존 리그를 재사용한다. 센서·방열판·일부 추진기·PD·미사일/프로브/어뢰 출구를 새 형태에 맞춰 연결했다. 네르갈 드론 베이는 새 트러스의 빈 공간을 피하여 전방 장갑 구획으로 이동했다. 새 함교 받침, 날개 위로 올린 프로브 출구, 지구 전함 상부 갑판 밖 미사일 출구는 연결/가림 검사에서 보완했다.

장갑판·볼트·표면 질감 등 최종 외장, 각 미사일 셀별 발사 애니메이션, 프로브 끝단 센서별 추가 성능은 이번 범위가 아니다. 방공 갑판/정찰 날개 등은 역할을 읽히게 하는 기본형이며 새로운 성능 보너스를 임의로 주지 않는다.

## 참고안 및 편집

- 내장 **image_gen**으로 생성한 3개 비교 보드: [`art/reference/20261017_t5_fleet/`](../../../art/reference/20261017_t5_fleet/). 전함 2종, 순양함 4종, 소형함 4종.
- 최종 프롬프트: [`prompts.json`](../../../art/reference/20261017_t5_fleet/prompts.json). CLI/API 우회 생성은 사용하지 않았다.
- 원본: `art/blender/<id>.blend`; 게임: `assets/ships/<id>.glb`; 형상 계약: `data/model_layouts/<id>.json`; 실제 초상화: `assets/ui/ships/<id>.png`.
- `tools/author-t5-layouts.py`는 형상 계약과 variant를 연결한다. `tools/build-t5-models.py`는 초기 기본형 제작용이다. **이후 수작업 수정한 Blender 원본은 재생성하지 말고 `tools/export-ship-models.py`로 내보낸다.**
- 기존 T4 소형 제작기의 공용 장비 함수는 가져올 수 있도록 main guard를 추가했다. 가져오기만 해서는 T4 모델을 다시 만들지 않는다.

## 검증

- `preservation-audit.json`: 기존 파일 99개 SHA-256 보존. 변경된 기존 파일은 T5 variant 10개와 모델 manifest. 성능 값 10종 동일, 두 데이터 생성기를 임시 디렉터리에서 실행한 뒤 전체 34함급과 연구 트리 동일.
- `geometry-audit.json`: 실제 Blender 좌표 476개, 최대 오차 약 0.000002m. 엔진 발광면 24개·프로브 출구 10개 가시성, 대형함 6종 수직 미사일 출구, 소형함 쌍미익 대칭, 부품 연결 후보 검사 통과. AABB 인접 검사는 보조 검사이며 렌더의 상/하/후면을 함께 확인한다.
- `sim-tier.log`: 682개. 독립 모델 34종, 신규 전 모듈 183개를 회전/큰 double 좌표에서 관통, 소형함 발사구·프로브 잔탄·어뢰 격리·편대/정찰/저장 검증.
- `sim-cruisers.log`: 220개. T5 순양함/전함 외피 진입과 주포·센서·방열판·추진기 도달 및 기존 방공/살보 검증.
- `sim-progression.log`: 558개. 연구/출격/보상/저장 이관/티어 매칭.
- `sim-hardpoints.log`: 67,127개. 34함급의 기본/교체 주포 정의, 회전/고각/포구, 실제 탄·장전·열·탄약 소모 호환성.
- 위 시뮬레이션 합계 **68,587개**. 게임 Debug 빌드 경고/오류 0.
- 실제 Godot 초상화/격납고 10종과 배포 EXE 검증 결과는 `portraits.log`, `*-hangar.png`, `release-verification.json`에 기록한다.

장기 혼성 함대전 승률, 240척 FPS/틱 비용, 플레이어 직접 비행은 이번 제작 검증에서 새로 측정하지 않았다. 수치 밸런스와 최종 외장은 기본형 전체를 갖춘 상태에서 조정한다.

## 배포

- 실행파일: [`SpaceFleet.exe`](../../../builds/SpaceFleet-20261017-t5-fleet-Windows-x64/SpaceFleet.exe)
- 배포 ZIP: [`SpaceFleet-20261017-t5-fleet-Windows-x64.zip`](../../../builds/SpaceFleet-20261017-t5-fleet-Windows-x64.zip)
- 실제 배포 EXE **15묶음 / 10,904개 통과**. 모델 검사 9,630개 포함. 장면/매칭/격납고/연구·출격/포탑·교체 무장/피격 시각효과/음향/망원/센서/AM/환경을 검사했다.
- ZIP CRC·SHA-256 일치, self-contained .NET 포함, 최종 ExportRelease DLL과 배포 DLL 해시 일치. `release-verification.json`에 자산·실행파일 증빙 기록.
- 전체 폴더를 유지한 채 `SpaceFleet.exe` 실행. 기존 연구 진행에 따라 T5를 해금한다. 검수 캡처의 34/34 보유 표시는 격리된 검사용 프로필이며 사용자의 기존 저장을 변경하지 않았다.
