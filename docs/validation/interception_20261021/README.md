# 미사일 센서 잠금·방공 사거리·레이저 자동사격 검증

2026-10-21. 비교 기준은 변경 전 `45c60da`의 시뮬레이션이다. 함선·무장 JSON의 피해량, 재장전, 회전속도, PD 사거리는 변경하지 않았다.

## 구현

- 미사일의 연소/관성비행 신호와 크기 제곱을 피탐지 계수로 사용한다. `SensorSignature=0.65`, `BurningSignature=2`는 미사일 정의의 조절 가능한 기본값이다.
- 기존 4Hz SensorNet에 접촉·식별·잠금, 관측 위치 오차, 관측함을 기록한다. 방공순양함의 소형 표적 추적 배율은 8, 요격함은 16이다. 함선 표적의 센서 성능은 그대로다. 아군 공유 관측·센서 손상·전력·화성 호위함 ECM·소행성 차폐를 반영한다. 프로브 단독 관측은 식별까지다.
- 주포·요격 미사일·PD·방어드론은 신선한 센서 잠금으로 교전한다. PD와 방공 주포는 잠금 전에도 관측 방향으로 추적할 수 있다. HUD는 적 미사일의 실제 좌표·내부 목표 대신 관측 위치와 접근 경로를 표시한다. 신호 소실 표식은 짧게 회색으로 유지한다.
- 주포의 공통 12km 요격 제한을 제거했다. 레일건은 해당 무장의 탄도 사거리, 레이저의 보조 조준·자동 요격은 출력 20%가 남는 거리(`2 × FalloffMeters`)까지다. 기본 방공 레이저는 40km, 교체형 대형 레이저는 70km다. 이는 센서 잠금·포각·선회·사선·열 조건이 충족됐을 때의 상한이다.
- 센서 오차와 무장별 거리 조준 오차를 실제 조준선에 더한다. 레이저는 그 광선이 미사일 충돌 구체에 닿았을 때만 피해를 준다. 별도 즉시 격추 확률은 추가하지 않았다. PD의 기존 통계형 판정에도 관측 오차를 반영한다.
- 대함 레이저 자동사격은 전달 출력 25% 이상에서 시작하고 20% 미만에서 중단한다. 경계에서 켜졌다 꺼지지 않도록 유지 구간을 둔다. 관측 오차가 표적 크기에 비해 너무 크면 대기한다. 방공순양함의 대함 조사는 열 55%에서 중단, 35% 이하에서 재개하여 요격 여유를 남긴다. 수동 대함 조사와 물리적 광선 범위는 유지한다.
- 사격 상태에 `사거리 밖 · 현재 / 한계 km`, `식별 · 잠금 대기`, `거리 감쇠로 대기 · 출력 %`, `조준 품질 부족`, `방공 대비 · 대함 조사 대기`를 구분한다. 사거리 수치는 가장 긴 유효 무장을 기준으로 안내하고, 실제 발사는 각 포탑의 조건을 확인한다.

## 접근 파형: 요격률과 명중 돌파율

조건: T3/T5 방공순양함, 주포 단독/주포+PD+드론, 출발 거리 8/16/24/32/48km, 12/48발, 시드 1~4. 실제 호위함 미사일을 완전 내구도·관성비행 2,000m/s로 투입한다. 보호 대상은 방공함 뒤 5km의 수동 전함이다. 함선 기동, 적 ECM, 디코이, 다른 공격 무장은 제외한다. 40초 동안 실제 60Hz/240Hz 전투 판정을 실행했다.

`출발 거리`는 시험 시작 시 방공함과의 거리다. 해당 거리에서 계속 쏘는 명중률을 뜻하지 않는다. 먼 거리에서 시작하면 탐지·선회·사격에 쓸 시간이 늘어난다. 변경 후 T5의 첫 조사는 이 관성비행 파형에서 최대 약 26.5km였다(이전 약 12km). 40km 전체를 활용하려면 더 강한 신호 또는 전방 아군의 잠금이 필요하다.

명중 돌파율은 살아남아 **방공함 또는 보호 전함에 실제 명중한** 비율이다. 보호 전함 중심 5km 경계를 통과한 `InnerScreen`과 다르며, 후자는 `ranges.csv`와 원본 JSON에 별도 기록했다. 일부 미사일은 경계 밖에서 방공함을 때리거나, 경계를 통과한 뒤 요격된다. 소멸·잔존도 별도 필드다.

32km보다 48km 파형의 요격률이 낮은 경우는 시드별 조준 오차의 시간 변화와 교전 순서가 달라진 결과다. 네 시드의 단순 비교이며 전체 함대전 승률이나 보편적인 거리 함수로 해석하지 않는다.

## 같은 거리에서의 실제 광선 명중

접근 시간이 길어서 생기는 이득과 거리 조준 오차를 분리하기 위해 T5의 2개 레이저로 정지한 미사일 구체를 6초 동안 추적했다. 대상 내구도만 충분히 높여 반복 측정하며, 실제 광선 충돌과 포탑 선회를 사용한다. 전방 아군이 잠금을 제공하는 조건의 4개 시드, 거리당 688회 조사 판정이다.

| 거리 | 미사일에 닿은 조사 판정 | 비율 |
|---:|---:|---:|
| 8km | 688 / 688 | 100.0% |
| 16km | 456 / 688 | 66.3% |
| 24km | 231 / 688 | 33.6% |
| 32km | 94 / 688 | 13.7% |
| 40km | 66 / 688 | 9.6% |
| 48km | 발사 없음 | 무장 요격 범위 밖 |

단독 관측에서는 같은 관성비행 대상의 32km 이상 잠금을 얻지 못해 발사하지 않았다. 이는 정지 표적의 **조사 명중 비율**이며 미사일 1발의 격추 확률이 아니다. 실제 돌파에는 미사일 내구도·출력 감쇠·노출 시간·기동·포탑 수·선회와 사각이 함께 작용한다.
