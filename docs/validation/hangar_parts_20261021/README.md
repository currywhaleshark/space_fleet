# 격납고 네 부품 메뉴 통일

기존 교체 계통과 새 절대값 부품 목록이 한 메뉴에 혼재하던 상태를 정리했다.

| 항목 | 새 교체 화면 |
|---|---|
| 주포 | 소켓별 주포 부품. 레일건/레이저 계통 전환은 모든 소켓을 함께 검증·교체 |
| 부포 | 근접방어 PD 부품 |
| 미사일 모듈 | 발사기 / 탄종 두 탭 |
| 발전 | 추가 발전기·냉각기 네 칸 |

엔진·센서·실드 및 베이 장비는 기존 기능을 유지한다. 새 부품도 기존 연구·용적·전력·함종 제한을 따른다. 무장 성능과 전투 판정 수치는 바꾸지 않았다.

구형 장착은 저장을 열었다는 이유로 초기화하지 않는다. 실제 장착 이름을 표시하고 새 부품 교체를 확인할 때만 해당 구형 선택을 제거한다. 구형 주포에서 전환하거나 무장 계통을 바꿔 여러 포탑이 영향을 받으면 확인창에 적용 범위를 명시한다. 기존 RP·연구 기록도 유지한다.

## 검증

- 게임 C# 빌드: 경고 0, 오류 0.
- Godot `--headless --fixed-fps 60 -- --hangar-test --seed=7`: **122개 통과**. 기존 메뉴 부재, 실제 설치 정보, 모달 취소·중복 방지·RP 재검증, 레일건↔레이저 전환, 구형 장비의 기본형 복귀, 네 항목 저장 및 개별/공유 프리셋, 실제 매칭·출격·조종 인계 포함.
- SimChecks Release: `--power-parts` 41개, `--ordnance-parts` 720개, `--hull-upgrades` 353개, `--squad-loadouts` 799개. 합계 **1,913개 통과**. 빌드의 기존 nullable 경고 6개는 유지.
- 실제 렌더러: 두 해상도 × 네 메뉴의 PNG 8개. 목록은 화면 위를 넘지 않으며 긴 발전 부품 목록은 스크롤한다. 확인창과 툴팁은 기존 접근성·입력 차단을 유지한다.
- 검사 프로필은 플레이어의 실제 저장을 읽거나 덮어쓰지 않는다.

화면 파일은 `MainGun`, `Secondary`, `Missiles`, `Generator`와 해상도로 구분한다. 스크린샷 프로필은 RP 0으로 시작하므로 미연구 부품이 연구 불가로 표시된다. 사유는 툴팁에서 확인할 수 있다.
