# 탄막형 부포의 요격 역할 수정 — 2026-10-16

사용자 의도: **탄막형은 미사일 요격에 유리해야 한다.** 이전 공통 피해 -10% 때문에 HP4 경량 미사일에 필요한 명중이 1→2회로 증가했다. 대미사일 피해를 분리해 이 역효과를 제거했다.

## 최종 성능과 구현

- 탄막형: 연사 +20%, **미사일·어뢰에 대한 발당 피해는 기본형과 동일**, 사거리 -15%, 기타 피해 -10%, 무장 전력 +3%.
- 기본 피해4인 함선에서 경량 미사일 HP4는 1명중, HP12 탄체는 3명중이다. 이전 탄막형 피해3.6에서는 각각 2/4명중이 필요했다.
- 드론·프로브 피해는3.6, 요격함에 대한 에너지/모듈 피해는18/9로 기존 탄막형의 손해를 유지한다. 포각·선회속도·선체/지형 가림·센서 판단은 그대로다.
- `ComponentEffects.MissileDamage`는 선택적인 전용 배율이다. 탄막형에1을 지정해 연구가 적용된 기반 부포의 요격 피해를 유지한다. 합성 결과는 `PointDefenseDefinition.MissileDamagePerHit`에 저장하며 실제 `EngagePointDefense`의 미사일 분기에서 사용한다. 어뢰도 같은 미사일 탄체 경로를 사용한다.
- 전용 값이 없으면 기존 `DamagePerHit`을 사용한다. null은 JSON에서 생략해 기본 34함급 정의/LoadoutId를 보존한다. 원거리형, 일반 부포, 드론의 독립 무장에는 새 보너스를 적용하지 않는다. 격납고 설명도 변경했다.

## 실측

6함체 × 2탄종(경량 HP4/일반 HP12) × 2속도(650/1,800m/s) × 시드1~8. 각 조건에서12발을0.3초 간격으로 유입시켰다. **각 형식192조건·2,304발**, 기본/수정 전 탄막/수정 후 탄막/원거리의 총768조건이다.

| 형식 | 요격 수/2,304발 |
|---|---:|
| 기본형 | 420 |
| 수정 전 탄막형 | 192 |
| 수정 후 탄막형 | **478** |
| 원거리형 | 297 |

수정 후 탄막형은 이 근거리 시험에서 기본형보다 요격 수가 **13.8% 증가**했다. 모든 개별 시드에서 우세하다는 뜻은 아니다. 빠른 중형탄 유입이나 요격함의 짧은 사거리에서는 기본형과 탄막형 모두 막지 못한 경우가 있다. 원거리형의 더 넓은 방어 구역은 이 시험의 평가 대상이 아니다.

500m에서 경량 미사일 한 발을 노출한 별도 시험(시드1~4)도 개선됐다.

| 방어함 | 기본형 평균 완료 | 수정 전 탄막 | 수정 후 탄막 |
|---|---:|---:|---:|
| 지구 전함 | 1.008초 | 1.321초 | **0.954초** |
| 지구 호위함 | 1.263초 | 1.592초 | **1.217초** |
| 지구 요격함 | 2.233초 | 3.817초 | **1.942초** |

발사 전 포탑 정렬 시간은 같으므로 연사 +20%가 전체 요격 시간 -20%를 뜻하지 않는다.

## 시험의 범위

- `salvos.json`: 실제 PD 포대 전체와 실제 탄체·내구도·신관·실드/장갑/모듈 피해를 사용한다. 드론은 제거했다. 함선은 정지 상태이며 체력·탄약을 리셋하지 않는다. 실패한 요격은 실제 피격과 계통 손상/격침으로 이어진다.
- 동일한 관측 방향을 만들기 위해 첫 포대 담당 방위의 고각45°에서 시작하고, 시작 거리는 **기본 사거리의70%**다. 따라서 세 형식의 공통 사거리 안에서 가까운 연속 유입을 비교한다. 시드는 좌우 유입 위치와 탄체 ID의 명중 난수를 바꾼다.
- 비행 중인 미사일을 정해진 속도로 생성하며 추진은 종료, 탐색기 갱신은 중지한다. 이후 위치를 덮어쓰지 않고 실제 이동·충돌을 실행한다. 자연 유도 비행이나 장거리부터 접근하는 전체 방어망의 최종 침투율 시험은 아니다. 미사일 요격과 표적 피해를 함께 검사해 표적 없는 무효 시험을 방지한다.
- `barrage-before` 대조군은 최종 탄막 정의에서 전용 미사일 피해만 제거해 이전3.6 경로를 재현한다. 이전 바이너리와 별개이며 다른 수치는 같게 유지한다.
- `pd-after.json`: 앞선 `component_combat_20261016/pd-fixed.json`과 같은432조건이다. **변경된36조건은 모두 탄막형의 대미사일 조건**이며, 기본형·원거리형과 모든 대함 결과는 동일하다. 이전 원자료는 덮어쓰지 않았다.
- 전체 수치는 [measurements.md](measurements.md), 검증/소스 및 원자료 해시는 [verification.json](verification.json)에 기록한다. 이 시험으로 함대 전체 승률이나 FPS 개선을 주장하지 않는다.

## 회귀 및 재현

전체 자동검사 **61묶음/5,677,201개**, 교체 계통 **2,033개** 통과. 기존 회귀 출력 및 기본34함급 정의/ID 동일. 신규 검사는 모든 함급의 대미사일 피해/기계적 제한, 실제 PD의 HP4/8/12 탄체 피해·요격 집계, JSON 왕복 및 잘못된 전용 피해값을 확인한다. 게임/Batch/ScaleBench 빌드 성공. 게임 빌드에는 NuGet 취약점 조회 실패 `NU1900` 경고4개가 있고 컴파일 오류는0이다. 배포 EXE와 커밋/푸시는 별도다.

```powershell
dotnet build tools/BattleBatch -c Release
dotnet tools/BattleBatch/bin/Release/net8.0/BattleBatch.dll --component-trials --phase pd --seeds 1,2,3,4 --jobs 2 --output docs/validation/pd_barrage_20261016/pd-after.json
dotnet tools/BattleBatch/bin/Release/net8.0/BattleBatch.dll --component-trials --phase pd-salvos --seeds 1,2,3,4,5,6,7,8 --jobs 2 --output docs/validation/pd_barrage_20261016/salvos.json
dotnet run --project tests/SimChecks -c Release -- --components
dotnet run --project tests/SimChecks -c Release
python -X utf8 docs/validation/pd_barrage_20261016/verify.py
```

검증 스크립트는 저장한 빌드/전체 검사 로그·정의 스냅샷도 읽는다. 후속 수치 실험은 별도 폴더에 남겨 이번 자료를 보존한다.
