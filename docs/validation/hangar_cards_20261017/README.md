# 격납고 카드 UI / 관전 음향 — 2026-10-17

## 변경

- 메인메뉴의 첫 진입을 격납고로 연결. 매칭 취소와 결과의 함선 변경도 격납고로 복귀한다. 전장·목표 설정 화면은 격납고의 `전장 설정`으로 접근한다.
- 편대와 연구 트리에는 실제 게임 함체를 렌더한 이미지와 함급 이름을 표시한다. 연구 카드에는 실제 RP 비용 또는 보유 상태를 표시한다.
- 주포·부포·엔진·센서·발전기·실드, 베이 장비, 영구 개량을 아이콘과 이름으로 선택한다. 장착/연구 가능 여부는 간단히 남기고 현재→교체 후 비교, 전력·질량, 이득/대가, 구체적인 불가 사유는 툴팁으로 옮겼다.
- 키보드로 장비 선택 후 F1로 상세창을 열고 Esc로 닫는다. 상세창의 Esc가 격납고 종료로 전달되지 않도록 처리했다.
- 외형 미리보기에서는 베이 표식과 클릭 판정을 함께 숨긴다. 베이/단면 모드에서는 실제 모듈 위치의 표식과 선택 기능을 유지한다.
- 관전 시 `null`을 넘겨 모든 음향을 비활성화하던 경로를 수정했다. 조종 소유권은 유지한 채 관전 함선을 구조 전달음 기준으로 사용한다. 주변 음향의 위치·방향은 기존 카메라 리스너를 유지한다.
- 관전 대상 변경 시 과거 사격/피격을 재생하지 않고, 대상 격침 시 다음 생존 함선을 따른다. 일시정지/복귀 동작도 유지한다.

## 검증

실제 Godot 4.7.2 .NET / Vulkan / RTX 2060에서 실행했다. `verify.ps1`은 별도 APPDATA와 테스트 프로필을 사용하므로 플레이어의 연구/세팅을 덮어쓰지 않는다. 화면에 보이는 전체 함급 보유/450 RP는 검증용 프로필이다.

| 검사 | 결과 |
|---|---:|
| 장면 진입/입력/복귀 | 51 통과 |
| 매칭/소유권/관전 + 관전 음향 | 40 통과 |
| 격납고/프리셋/장비/상세창/출격 | 40 통과 |
| 연구 구매/해금/보상/재출격 | 32 통과 |
| 무기/추진/피격 음향 + 실제 믹서 출력 | 120 통과 |
| 주변 함대 음향/거리/방향/일시정지 | 120 통과 |
| 합계 | 503 통과 |

음향 회귀검사의 실제 녹음 peak는 0.444. 함대 음향은 방향 전환 시 L/R 값이 바뀌며, 음소거/일시정지 구간은 0으로 확인했다. 관전 경로는 엔진 재생, 사격/피격 이벤트, 주변 엔진, 대상 전환/격침, 소유권과 AI 보존을 별도로 검사했다. 장시간 수동 전투에서의 주관적인 음량 평가는 이번 자동검사 범위에 포함하지 않았다.

1600×900 / 1280×720에서 이미지 카드, 긴 함급명, 베이 장비와 F1 상세창을 캡처하고 눈으로 확인했다. 아래 PNG는 최종 소스의 실제 렌더이다.

- `hangar.png`, `hangar-small.png`
- `equipment.png`
- `research.png`, `research-mars.png`
- `details.png`

C# 빌드 성공. NuGet 취약점 조회 서버에 접근하지 못하는 NU1900 경고만 발생했다. 시뮬레이션 성능/밸런스 데이터는 수정하지 않았다.

함선 이미지 10개는 총 약 348 KiB이며 같은 모델을 쓰는 함급이 공유한다. 카드에 실시간 3D 장면을 추가하지 않는다. 재생성 방법은 `assets/ui/README.md`에 기록했다.

배포본 검사와 파일 무결성 결과는 `release-verification.json`에 기록한다.
