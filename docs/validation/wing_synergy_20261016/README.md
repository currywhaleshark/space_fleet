# 요격함 추가 조합 비교 — 2026-10-16

요격함을 포함하면 일부 역전과 실제 방공·강습 기여가 생기지만, **근거리 지구 / 장거리 화성의 큰 편중은 유지**된다. 이번에는 수치를 더 조정하지 않았다. 우선 검토할 것은 전함 교전의 짧은 생존시간과 요격함 강습 도착시간의 간격이다.

## 결과

각 칸은 **지구 승 : 화성 승**, 64판이다. 무승부와 시간 제한 종료는 없었다.

| 시작 거리 | 양측 요격함 없음 | 양측 요격함 5척 | 지구만 요격함 5척 | 화성만 요격함 5척 |
|---|---:|---:|---:|---:|
| 20km | 61 : 3 | **64 : 0** | 64 : 0 | 46 : 18 |
| 70km | 64 : 0 | **58 : 6** | 64 : 0 | 57 : 7 |

한쪽만 추가한 조건은 함대 척수 자체가 다른 민감도 시험이다. 동일 전력 대결의 승률로 취급하지 않는다. 양측 편대 조건의 팀별 결과도 20km 지구 32/32 대 32/32, 70km 지구 28/32 대 30/32, 130km 지구 2/32 대 3/32여서 이번 거리별 쏠림은 특정 팀 위치 하나로 설명되지 않는다.

양측 편대 조건의 실제 요격함 기여(거리마다 64판 합계):

| 거리 | 지구 미사일 요격 | 화성 미사일 요격 | 지구 어뢰 명중/발사 | 화성 어뢰 명중/발사 | 내부 모듈 피해 기여 지구/화성 |
|---|---:|---:|---:|---:|---:|
| 20km | 431 | 343 | 0/0 | 1/2 | 3.0% / 5.1% |
| 70km | 0 | 0 | 4/20 | 124/267 | 2.5% / 26.8% |
| 130km | 191 | 71 | 26/93 | 32/125 | 21.3% / 12.5% |

70km 지구 요격함은 일반 미사일 외에 어뢰 2발을 요격했다. 화성의 70km 어뢰 명중률은 46.4%로, 어뢰 자체가 전혀 명중하지 못하는 상태는 아니다. 20km 지구 미사일 요격 431건 중 419건은 요격용 미사일에 의한 격추다. 장비와 임무의 방공 기여가 실제로 발생했다.

그러나 공격 시점의 간격이 크다.

- **20km:** 화성 전함 62척이 격침되고 2척은 최종 무력화 상태였다. 격침된 전함의 격침시각 중앙값은 약 10초. 양측 어뢰 총 2발로, 대부분은 주포전·방공·소형함 교전으로 끝났다.
- **70km:** 화성 전함 62/64척이 먼저 격침됐다. 격침시각 중앙값은 약 21초인 반면, 완료된 화성 어뢰 비행 기록이 있는 30판의 첫 발사 중앙값은 약 133초다. 완료된 화성 어뢰 260발 중 **229발은 자기 전함 격침 후 발사**, 31발은 첫 전함 격침 전에 발사됐다. 예비/초기 집계에서는 선제 발사가 없었지만 전체 시드에서 일부 확인됐다. 지구 전함이 먼저 격침된 것은 2판인데 화성이 6판을 이겼으므로, 최소 4판은 화성 전함을 먼저 잃고 남은 전력이 역전했다.
- **130km:** 지구 전함이 61/64판에서 먼저 격침됐다. 지구 전함 격침시각 중앙값 약 66초, 지구 요격함의 강습 명령 배정 중앙값 224초. 완료된 지구 어뢰 기록이 있는 16판의 첫 발사 중앙값은 약 413초다. 완료된 지구 어뢰 88발은 전부 자기 전함 격침 이후 발사됐다. 양측 완료 어뢰 199발 모두 첫 전함 격침 이후였다. 지구 전함의 주포 미발사도 **8/64→10/64척**으로 해소되지 않았다.

격침/발사 중앙값은 해당 사건이 발생한 표본만의 값이며 동일한 분모가 아니다. 지연 판단은 사건 시각을 같은 전투 안에서 직접 비교한 어뢰 건수를 함께 근거로 삼는다. 요격함 생존 척수가 많거나 전투가 오래 지속됐다는 사실만으로 주력함 보호가 성공했다고 판단하지 않는다.

정찰도 작동했다. 양측 편대의 프로브 발사는 지구 20/70/130km에서 64/80/46개, 화성 0/0/132개였다. 130km 신규 접촉/식별 기여는 지구 2/6, 화성 3/26이다. 이 시험은 개활지이며 전함·호위함 센서도 있으므로 정찰 가치 전체를 평가하는 조건은 아니다.

## 판단과 다음 검증

요격함 포함 여부를 보기 전에 주포 장전·오차만 더 조정하지 않은 것이 적절했다. 실제 방공과 반물질 강습은 기여하지만 현재 소규모 조합에서는 전함이 먼저 결판나는 경우가 많다. 특히 70km에서는 강습 명령 자체가 시작 시점부터 배정되는데도 이동·집결·침투에 시간이 걸린다. 이를 전부 AI의 늦은 임무 전환으로 설명하거나 즉시 돌격 명령으로만 해결하지 않는다.

후속 시험은 **전함의 첫 유효 포격 이후 생존시간**, **요격함의 초기 전개 위치와 실제 진입시간**, **130km 지구 전함의 잠금 유지/재획득 실패**를 우선 분리해 비교한다. 그 뒤 주포 장전/명중 오차와 강습 효율을 재평가한다. 화성 전함 단독의 소폭 우세와 지구 함대의 방공·지속전 시너지라는 방향은 유지하며 모든 조합을 50:50으로 맞추지 않는다. 이번 16척 비교를 10:10 편대·소행성·플레이어 직접 조종의 최종 밸런스로 일반화하지 않는다.

## 조건

직전 장전·사격 오차 조정 상태를 고정하고, 양측 **전함 1척 + 호위함 2척**에 기본 요격함 5척의 편대를 추가한다. 지구는 `interceptor`, 화성은 `mars_interceptor`이며 정찰 T3/강습 T3 분기 함체를 섞지 않는다. 앞선 24척 시험은 호위함 6척과 T3 소형함 5척을 사용했으므로 이번 직접 비교와 구분한다.

- 요격 편대 없음 / 양측 5척 / 지구만 5척 / 화성만 5척의 네 조건.
- 시작 거리 20/70/130km, 위치 시드 1~16, Blue/Red 팀 교환, 공간 위치 교환. 조건별 64판, 본시험 총 768판.
- 전함·호위함의 시작 위치·자세·호출부호·설계·전투단 구성과 지휘관 규칙은 같다. 요격함은 별도 `InterceptorWing`으로 기존 자동 임무를 사용한다. 강제 강습 명령이나 추가 센서 정보를 제공하지 않는다.
- DeepSpace, 60Hz, 섬멸전, 최대 25분. 기존 함체·모듈·무장·AI 수치를 변경하지 않는다.
- 예비 시드 1의 48판은 본시험과 중복된다. 독립 표본으로 더하지 않고 재현성 확인에만 쓴다. 16개 시드의 팀/공간 교환 역시 64개의 독립적인 무작위 시드는 아니다.

## 해석 기준

기존 섬멸전은 기함 상실과 잔여 전력 비율로 종료한다. 현재 전력 가중치는 전함 6, 호위함 2, 요격함 0.5다. 요격함 없이 전함만 잃으면 잔여 4/10으로 종료할 수 있지만, 5척을 추가한 뒤 전함만 잃으면 6.5/12.5로 50%를 넘는다. 따라서 전투시간 증가를 전함 생존성 개선으로 해석하지 않는다. 전함 격침 시점·종료 시 운용 가능 여부, 실제 요격·피해·어뢰 기록을 함께 본다.

`FirstAction`은 방어 위치 도착도 포함하므로 첫 피해 발생 시각과 다르다. `FirstAssault`는 실제 강습 명령 배정 기록이며 어뢰 발사 시각은 `AntimatterFlights.LaunchTime`으로 별도 확인한다. 임무 체류시간은 생존 편대 단위이고, 각 함의 손상/탄약 부족에 따른 개별 복귀는 편대 임무와 다를 수 있다.

프로브 접촉/식별은 해당 시점에 함선 센서만으로 부족한 관측을 프로브가 보완한 신규 기여다. 함대가 과거에 한 번도 보지 못한 새 적의 수와 같지는 않다. 센서가 이미 충분한 개활지 전투에서 수치가 낮다고 정찰 장비가 작동하지 않는 것으로 해석하지 않는다.

어뢰 명중률의 분모는 발사 수다. 비행 결과 목록은 종료된 탄만 포함하므로 판정 순간 비행 중인 탄은 별도이며, PD/드론 방어와 유효시간 소멸을 구분한다. 미사일 발사 수에는 요격용 발사도 포함한다. 함종별 피해 기여는 실드 피해와 내부 모듈 피해를 구분하고, 내부 모듈 피해 비중을 선체 구조 피해 비중으로 해석하지 않는다.

직전 수치 조정의 `../gunnery_tuning_20261016/final.json.gz`를 무편대 대조군으로 자동 비교한다. 다른 수치로 후속 측정할 때는 그 수치의 대조군을 준비하고 `--baseline`에 전달한다. 배치 병렬 실행의 `WallSeconds`는 CPU 경합을 포함하므로 성능 벤치마크로 사용하지 않는다.

첫 본시험은 디스크 공간 부족으로 텔레메트리 저장 중 중단됐다. `aborted-run.json`과 `aborted.traces.zip`에 당시 기록을 분리하고 승패 통계에서는 제외했다. 예비 48판의 `pilot.json.gz`와 `pilot.traces.zip`은 정상 완료 자료다. 이후 4개 시드씩 압축 JSON으로 직접 저장하는 방식으로 본시험 전체를 재실행했다. 실제 명령과 측정 바이너리/소스 해시는 `run.json`, 최종 통계 원본은 `results-s1/s5/s9/s13.json.gz`다. 최종 원본은 모든 함선·편대별 통계와 피해 사건, 어뢰/프로브 비행 결과를 보존하며, 전체 5초 텔레메트리는 예비시험에만 있다.
