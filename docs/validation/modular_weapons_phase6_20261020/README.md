# 모듈식 무장 6단계 검증: 센서 동시 락온, Blender 무장 키트 (2026-10-20)

계약: `docs/DESIGN_modular_weapons.md` §22.

## 동시 락온과 다중 표적 일제사격

- 채널: 요격·정찰·강습 1, 호위·순양함 2, 전함 3, 미사일순양함·장거리 센서 +1.
- 다중 셀 발사기만 일제사격을 [주표적, 주표적에 가까운 다른 락온 적함…]에 차례로 나눈다. 단일 발사관은 지정 표적만 쏜다.
- 검사 `--multi-lock` 11개 통과. 실제 AI가 락온된 적 호위함을 상대로 40초 동안 쏜 결과는 다음과 같다(발사 수 / 표적 수 / 한 표적 최다).

| 발사함 | 결과 |
|---|---|
| 화성 T4 미사일순양함, 단일 발사관, 적 3척 | 8발 / 1척 / 8발 |
| 같은 함, 8셀(채널 3), 적 3척 | 16발 / 3척 / 6발 |
| 같은 함, 8셀, 적 2척 | 16발 / 2척 / 8발 |
| 지구 호위함, 2셀(채널 2), 적 3척 | 4발 / 2척 / 2발 |

- 실전 통제 실험(`forced_launchers.txt`, 부품당 32경기)
  - 동시 락온만 넣었을 때 2셀 +6.6%, 4셀 +10.0%, 8셀 +5.8%로 강해졌다.
  - 장전·탄창을 조정해 **+3.7% / +4.4% / +5.3%**가 됐다.

## Blender 무장 키트

- `tools/build-weapon-kit.py`(Blender 5.1, 백그라운드)
  - 원본 `art/blender/weapon_kit.blend`와 `assets/weapons/weapon_kit.glb`를 만든다.
  - 부품 9종이다. 모두 단위 크기이고, 재질 이름으로 함선 팔레트를 입는다.
  - 다시 만들 때: `blender --background --python tools/build-weapon-kit.py -- --root <repo>`.
- 바뀐 소켓의 포신(`shots/*_turret_kit.png`)은 키트의 레일(홈이 있는 지구형·열린 화성형), 둥근 덮개·절연 마디, 지구 방패판, 화성 방열판으로 조립한다. 배치와 포구는 2단계 규칙 그대로다.
- 다중 셀 발사기(`shots/mars_missile_cruiser_t4_launcher_vls8.png`)는 셀마다 해치를 실제 발사 위치에 놓고, 선체로 내려가는 받침을 둔다.
- 고정 축선 중형포(`shots/interceptor_t3_front_axial.png`)는 기수 아래 수신기 포드를 단다.
- 렌더러 모델 검사 10,975개 통과. 새 항목은 다음과 같다.
  - 키트 로드
  - 해치 수 = 셀 수, 해치 위치 = 실제 발사 위치(2·4·8셀)
  - 단일 발사관과 기본 축선포는 기존 모델 그대로
  - 중형 축선포 수신기 존재

## 함께 고친 것

- 매칭 흐름에서 화면 평면에 가까운 표적을 가리키는 편대 명령 화살촉이 삼각분할되지 않아 오류가 찍혔다. 화살촉 세 점이 유한하고 넓이가 있을 때만 그린다.

## 검사

- 전체 SimChecks 68묶음 5,795,002개 통과(발사기 조정 전 실행). 조정 후 `--ordnance-parts` 720개·`--multi-lock` 11개를 다시 통과했다.
- 실제 렌더러: 모델 10,975, 격납고 83, 매칭 흐름 43 통과(삼각분할 오류 0).

## 남은 것

- 레이저 부품과 PD 부품의 외형은 아직 키트를 쓰지 않는다.
- 기본 소켓의 Blender 포신은 함선 원본 그대로다. 키트로 교체하지 않았다.
- 새 포탑 자리 추가(소켓 수 증가)는 함선 모델 편집이 필요해 이번 단계에서도 하지 않았다.
