# T4 소형함 기본형 참고

내장 image_gen으로 생성한 `t4-small.png`와 정확한 프롬프트 `prompt.json`을 보존한다. 좌상 카노푸스, 우상 사크르, 좌하 포보스, 우하 하위헌스다.

넓은 정찰 날개와 센서 귀 / 전진익 방공형 / 삼각익 강습형 / 카나드와 좁은 후퇴익 기동형이라는 큰 실루엣을 채택했다. 사진의 앞을 향한 엔진 구멍은 채택하지 않았으며 게임 추진기는 모두 후방으로 열려 있다. 주포는 실제 데이터대로 고정식 단일 포구이며 양옆의 두 부재는 가속 레일이다.

실제 구성은 네 함 모두 일반 미사일 4발, 카노푸스·사크르 PD 2기 / 포보스·하위헌스 PD 1기다. 프로브 5/2/0/2개와 AM 1/3/5/3발을 유지했다. 기존 길이 기준은 지구 30m / 화성 26m다. 패널·볼트·최종 재질·수납 애니메이션은 후속 공정이다.
