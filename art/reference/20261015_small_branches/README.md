## 다음 모델 작업 기준

1. 기존 Blender 원본을 보존하고 함급별 별도 파일에서 단순 면으로 선체 외곽부터 만든다. 게임 좌표는 전방 -Z, 위 +Y, 우현 +X다.
2. 모델 안에 내부 모듈 체적, 전방 주포와 탄약고, 함교/센서, 반응로, 양쪽 발전/전력망/냉각, 실드 계통을 배치한다. 모듈이 선체 밖에 뜨지 않도록 확인한다.
3. 격리용기를 반응로와 분리하고 실제 탄두 크기, 발사·전량 투기 경로를 확보한다. 정찰함 1발과 강습함 4발을 같은 부피에 억지로 넣지 않는다.
4. PD 피벗·포구와 회전 한계, 선체에 가리는 하방/후방 사각을 확인한다. 센서·방열판·주엔진·RCS에도 실제 손상 위치와 효과 소켓을 연결한다.
5. 단순 모델과 JSON의 위치를 함께 검증한 뒤 정면/측후방 피탄, 여러 모듈의 동시 관통, 방공 사각, AM 접근/명중/이탈을 시험한다. 배치와 수치가 안정된 뒤 외장 패널·배관·재질·데칼을 추가한다.

생성 이미지에 보이는 세밀한 패널은 분위기 참고다. 다음 모델에서 모두 재현할 필요는 없으며, 먼저 큰 구조와 장비 위치를 검증한다.
