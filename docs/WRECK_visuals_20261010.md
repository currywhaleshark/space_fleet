# 잔해 소등·내부 구조·외장 탈락

사용자가 보완한 `f0f8adb`의 6종 Blender/GLB를 그대로 사용한다. 원본 모델·함체 JSON·시뮬레이션 피해와 충돌 판정은 변경하지 않았다.

## 표현

- 새 패널 셰이더에 함선별 전원과 잔해 그을림을 연결했다. 발전 정지로 무력화되면 선체 형태를 유지하며 작업등이 꺼진다. 복구하면 다시 켜진다. 잔해 재질을 별도로 복제하므로 다른 정상 함선의 조명·색은 바뀌지 않는다.
- 실제 메시를 절단하고, 연결된 각 형상의 단면에 골조·설비 상자·배관·끊어진 끝과 잔열을 만든다. 전체 충돌 상자를 막는 방식에서 벗어나 화성 함선의 열린 트러스 공간을 보존한다. 단면의 작은 설비는 장식이며 새로운 기능 모듈이나 정밀한 내부 설계도가 아니다.
- GLB가 합쳐 놓은 메시에서 위치가 연결된 형상을 구분해 장갑판·방열판 후보를 찾는다. 크기·얇기·재질·파단 위치를 기준으로 선택한다. 원래 표면을 큰 잔해에서 제거하고 동일한 형상을 날려 보내므로 중복 장갑판을 덧붙이지 않는다.
- 탈락 부품은 약 0.15~0.50초 뒤 큰 조각의 운동을 이어받아 회전하며 흩어진다. 전함/호위함/요격함은 각각 최대 24/16/8개(두 동강일 때 18/12/6개)이며, 22~25초 뒤 정리한다. 작은 부품은 시각 효과이고, 기존 큰 잔해의 충돌 상자는 유지한다.
- 무력화는 분해하지 않는다. 구조·충돌·탄약고는 기본 2분할, 반응로·반물질 유폭은 최대 8분할이다. 빈 구역은 생략하므로 현재 호위함의 특정 유폭은 6개 큰 조각으로 남는다. 절단은 여전히 평면 기반이며 재질별 물리 파괴 해석은 아니다.
- 조각으로 바뀌어도 장갑판 셰이더의 모델 좌표와 UV를 보존한다. 노출 내부의 잔열은 감쇠하여 16초에 완전히 꺼진다.

## 생성 비용과 수명

연결 형상 분석은 GLB 메시별로 함선 로딩 때 캐시한다. 잔해 생성은 프레임 전체 공유 목표 예산 4ms로 분할하며, 한 번 시작한 메시 업로드나 단면 작업은 도중에 중단하지 않으므로 4ms를 넘을 수 있다. 생성 중에는 소등된 기존 형체와 폭발을 유지하고 완성된 잔해로 한꺼번에 전환한다. 다수 함선이 동시에 파괴되면 전환은 늦어질 수 있다.

최종 Windows Release 검사의 6종·2가지 파괴에서 생성의 총 CPU 작업 시간은 약 17~128ms, 가장 긴 개별 작업은 약 4~19ms였다. 검사는 같은 작업들을 강제로 끝까지 실행해 정확성을 검증한 값이며 전체 게임의 프레임 시간/FPS 측정은 아니다. 표시 장면에서는 프레임 분할 경로를 사용해 정상적으로 완성됨을 별도 확인했다.

복구·씬 종료는 미완성 생성기를 취소한다. 이전 노드와 탈락 부품을 장면에서 즉시 떼고 정리하므로 같은 프레임에 다시 파괴해도 중복되지 않는다. 시뮬레이션 시간으로 움직여 일시정지 시 정지하며, 렌더 원점을 1e12m 이동해도 위치를 유지한다.

## 검증과 재현

실제 GPU 전투 시각 검사 216개: 기존 36개와 새 잔해 검사 180개. 6종 모두 소등/복구·다른 함선 재질 격리·2/최대8 분할·실제 외장 탈락·상한·절단면·좌표 이동·시간 건너뛰기·수명 종료·생성 도중 복구를 확인한다. 함선 모델 1,204개, 장면 46개, 자함 음향 116개, 주변 음향 104개와 함께 배포본에서 검사한다.

```powershell
.\tools\run.ps1 --combat-visual-test
.\tools\shot.ps1 wreck-earth-bb --fx-preview=breakup --fx-ship=battleship --fx-age=4
.\tools\shot.ps1 wreck-mars-bb --fx-preview=breakup --fx-ship=mars_battleship --fx-view=section --fx-age=4
.\tools\shot.ps1 wreck-mars-dd --fx-preview=breakup --fx-ship=mars_escort --fx-view=section --fx-age=4
.\tools\shot.ps1 wreck-phobos --fx-preview=shatter --fx-ship=mars_interceptor --fx-age=2.5
```

작은 함선의 검토 카메라는 길이에 맞춰 Near/Far 범위를 줄여 광원 절두체 계산 오류를 방지한다. `--fx-view=section`은 절단면을 따라가는 근접 시점이고 `cut`은 분리된 두 구역을 함께 보는 시점이다. 검토 장면은 게임의 `BattleLook` 조명과 하늘을 사용한다.
