# T1 시작 호위함 참고안

사용자가 T1도 별도 기본형으로 정리하도록 지시했다. `t1-starters.png`는 내장 image_gen으로 만든 비교 참고안이며, 정확한 프롬프트와 생성 방식은 `prompt.json`에 있다.

- 제피르: 둔한 장갑 선수, 낮은 함교, 수평 방열판, 초급 호위함의 단순한 갑판 구성.
- 루나에: 가는 선수, 외부 센서, 후방 노출 기관 구획과 구조재, 수직 방열판.
- 그림의 장비 수나 크기를 그대로 복사하지 않았다. 기존 게임 정의의 연장포 1기, 미사일 12발, PD 4기/2기와 소형 센서·ECM 베이 1개를 기준으로 모델링했다.
- 이번 결과는 기능 배치와 큰 형태를 검증하는 Blender 기본형이다. 최종 패널, 볼트, 텍스처, 수납 애니메이션은 후속이다.

예전 T2 축소 원본은 `art/archive/20261017_t1_scaled_originals/`에 보관했다. 활성 모델은 `art/blender/earth_starter_escort.blend`와 `mars_starter_escort.blend`다.
