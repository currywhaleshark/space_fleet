# 엔진·센서·실드 부품 교체

세 계통의 구형 교체 UI를 앞서 정리한 부품 선택 방식으로 통일했다. 부품 아이콘과 이름으로 선택하고, 툴팁과 확인창에서 현재 → 교체 후 수치 및 전력·질량을 비교한다.

| 계통 | 선택형 | 진영별 1회 연구 |
|---|---|---|
| 엔진 | 고추력 / 기동형 | 각각 90 RP |
| 센서 | 장거리 / 저피탐 | 각각 80 RP |
| 실드 | 고용량 / 고속재생 | 각각 90 RP |

각 계통에 무료 표준형이 있다. 장거리 센서의 추가 잠금 채널도 비교에 표시한다. 기존 구형 연구는 해당 새 부품의 연구로 인정하며 이미 지불한 비용을 다시 받지 않는다. 기존 장착 자체는 저장을 읽을 때 변경하지 않고, 확인한 계통만 새 선택으로 교체한다. 기존 부품 카탈로그와 선택 필드는 구형 저장 호환용으로 남아 있다.

`SystemParts`는 기준 호위함의 절대 추력·전력·센서·실드 수치를 기본형 대비 비율로 합성한다. 초기 선택형의 전투 성능은 기존 배율 카탈로그와 같도록 정했으며 새 밸런스 조정은 하지 않았다. 전력 예산과 질량 부담을 적용하고, 기존 물리 모듈·손상·복구를 유지한다. 주포 용적이나 추가 장착 칸을 새로 만들지 않는다.

## 검증

- 게임 빌드: 경고 0, 오류 0. SimChecks 빌드: 기존 nullable 경고 6, 오류 0.
- `--system-parts`: **3,379개**. 모든 플레이 가능 함급의 기본/전체 영구 개량 상태에서 구형과 새 부품 성능 비교, 명시적 기본 부품의 해시 불변, 합산 질량, 잠금 채널, 모듈·무장 위치, 전력 초과 거부, 실제 추력 및 전력 진행, 모듈 파괴/복구.
- `--components`: **2,237개**, `--multi-lock`: **11개**, `--power-parts`: **41개**, `--ordnance-parts`: **720개**, `--hull-upgrades`: **353개**, `--squad-loadouts`: **799개**. 합계 **7,540개**.
- Godot `--headless --fixed-fps 60 -- --hangar-test --seed=7`: **160개**. 일곱 메뉴의 구형 목록 부재, 실제 버튼 연구/교체, 취소, 중복 확인, 확인 시 RP 재검증, 구형 교체 무료 이관, 기본형 복귀, 개별/공유 분리, 저장, 매칭 스냅샷, 출격·조종 인계.
- 실제 Godot 렌더 **9장** 확인: 세 메뉴 및 교체 확인창 각각 1600×900 / 1280×720, 추가로 1280×720 센서 상세 팝업. 메뉴·비교 수치·RP 비용·확인/취소 버튼의 잘림 없음.
- 검사와 렌더는 격리된 프로필을 사용하여 실제 사용자 저장에 쓰지 않는다. 스크린샷 메뉴의 RP 0은 검사 프로필 값이며, 연구 불가 사유와 필요 비용은 툴팁에 표시한다.

로그는 이 폴더에 보존한다. 장시간 함대 승률·FPS 비교나 새 배포 실행파일 생성은 이번 검증 범위에 포함하지 않았다.
