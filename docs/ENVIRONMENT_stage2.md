## 1차 — 전장 선택·생성·표시

- `BattleConfig`에 전투 시드와 독립적인 `Battlefield`/`FieldSeed`. 출격 화면의 전장 버튼, 직접 실행 `--battlefield=AsteroidCluster --field-seed=3`, 배치의 `-Battlefield AsteroidCluster -FieldSeeds 1,2,3`를 연결했다. 여러 배치 시드는 각각 `-fieldN` 파일 묶음과 `.field.json`을 남긴다. 기존 요약 형식은 유지한다.
- `AsteroidField`: 타원체 70/25/35km, 3개 크기층, 경계 구 사이 300m, 출발점 25km·거점 7km 비움. 자체 난수열을 사용한다. 중심 반전은 구성 구의 위치와 표면 변주까지 반영한다. 구 2~4개로 만든 12종 메시와 재질 하나를 공유한다. 지형은 고정이며 그림자는 끈다.
- 같은 배치 시드로 모드별 차이를 비교할 수 있도록 **거점이 없는 모드에서도 같은 거점 위치를 비워 둔다**. 이후 경로 검사의 목적지가 바위 속에 놓이지 않도록 **군집 중심 2.5km도 비워 둔다**. 이는 장애물 배치에만 적용하며 거점 좌표·점령 규칙을 바꾸지 않는다.
