# T3 알타이르·데이모스 기능 블록아웃

2026-10-15. 레퍼런스 승인 후 별도 Blender 원본과 GLB를 만들고 T3 두 함급에 연결했다.
큰 면과 장비 구획을 검토하는 단계이며, 최종 외장 마감이나 밸런스 확정본은 아니다.

| 항목 | 알타이르 `earth_recon_t3` | 데이모스 `mars_assault_t3` |
|---|---|---|
| 공칭 길이 | 30m | 26m |
| 형태 | 평평한 센서 노즈, 측면 프로브, 긴 주선체 | 쐐기형 기수, 깊은 격리실, 큰 쌍발 엔진 |
| 프로브 / 일반 미사일 / AM | 4 / 4 / 1 | 0 / 4 / 4 |
| PD | 하부 1기 + 후방 상부 1기 | 후방 상부 1기 |
| 모듈 / 주 엔진 / RCS | 16 / 2 / 14 | 16 / 2 / 14 |

## 원본과 재현

- `art/blender/earth_recon_t3.blend`, `art/blender/mars_assault_t3.blend`: 개별 부품, PD yaw/pitch, 모듈 가이드와 각 소켓을 편집할 수 있다.
- `assets/ships/`의 동일 ID GLB와 manifest: 정적 본체 및 PD 움직이는 그룹만 병합한다.
- `data/model_layouts/`: 구획, 모듈, 장착 베이, 발사구, PD 좌표 원본. `tools/generate-tier-variants.py`가 성능 계산 후 적용한다. T4/T5는 계속 기존 모델을 쓴다.
- 재생성: `blender --background --factory-startup --python-exit-code 1 --python tools/build-small-branch-models.py -- --root <repo> --render`. **이 명령은 신규 두 Blender 원본도 재생성한다. 수동 편집 후에는 실행하지 않는다.**
- 수동 편집 후 내보내기: `tools/export-ship-models.py --root <repo> --ship <ID>`를 Blender Python으로 실행한다. 합성된 variant 정의와 소켓을 비교한다.
- 읽기 전용 점검/모듈 렌더: `tools/audit-small-branch-models.py`. 원본이나 GLB를 저장하지 않는다.

## 확인한 것

- Blender 소켓 25/20개가 JSON과 1mm 이내 일치. 미러링한 꼬리날개 대칭, 주 엔진 정확히 2개, AABB 접촉 그래프가 모델별 한 덩어리. 이 그래프는 떨어진 부품 후보 검사이며 닫힌 단일 메시를 의미하지 않는다. 정면·후면·상면·하부도 시각 확인했다.
- 모든 모듈이 피해 구획 안에 들어가고 모듈끼리 체적이 겹치지 않는다. 전방 센서/주포, 중앙 AM, 후방 반응로, 좌우 발전/전력/냉각, 외부 엔진 포드를 분리했다.
- 게임 모델 검사 2,484개 통과: 임포트/스케일/팀 재질, 모듈/포구/PD 좌표, 실제 PD yaw/pitch 추적, 엔진별 파괴에 따른 추진광 소멸, RCS 반응.
- 전체 SimChecks 통과. 신규 갈래 검사는 224→255개: 회전된 함체와 1e12m 좌표의 실제 프로브 출구, 4회 소모, 지도 범위/실제 비행 거리 일치, 미사일/AM 별도 발사구와 재고도 검사한다. 기존 함선은 `launchPoints` 미설정으로 원래 사출 방식 유지.
- `branch-trials.json`: 동일 단독 임무 6조건, 각 150초. T3 알타이르 편대는 프로브 5개 전개·강습 없음·최근접 26.20km. T3 데이모스 편대는 39초 집결 후 공동 강습·AM 5발 발사/5발 명중·5척 생존. **비무장 표적 조건이므로 실전 승률이나 PD 돌파 성능을 입증하지 않는다.**
- `before-sha256.json` 대비 기존 8개 `.blend`/GLB와 원본 함선 6개 보존. 기존 variant 중 바뀐 것은 T3 두 개뿐. 재생성 반복 결과와 검사 합계는 `verification.json`.

## 렌더와 남은 작업

`*_hero.png`, `*_aft.png`, `*_underside.png`, `*_top.png`는 Blender 검토용이다.
`*_game.png`는 실제 게임의 모델 갤러리에서 촬영했다. `*_modules.png`는 내부 판정 체적과 실제 외피 와이어를 함께 표시한다.
모듈 색: 청록=센서, 회색=주포, 붉은색=탄약고, 주황=AM, 보라=반응로, 청색=엔진, 녹청=냉각, 노랑=전력망, 황토=발전기, 연두=기동/실드.

무기 피해량·연사력·탄약 수·내구력 수치는 유지했다. 실제 외곽과 구획은 바뀌었으므로 다음 작업은 피탄/방공 사각/AM 진입·이탈 및 함대전 비교다. 장갑 판정은 기존 AABB 방식이라 경사면/핀을 근사한다. 투기 하부 해치와 경로는 모델에 확보했으며 개폐 애니메이션·잔탄별 외형 변화·패널/배관/데칼/최종 재질은 후속이다. EXE와 커밋/푸시는 이번 작업에서 만들지 않았다.
