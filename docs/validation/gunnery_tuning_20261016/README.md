# 전함 주포 장전·명중 오차 소폭 조정 — 2026-10-16

지구 전함의 기본 재장전 시간을 **3.00→3.15초(+5%)**, 화성 전함의 사격통제 오차 배율을 **1.00→1.10(+10%)**로 조정했다. 화성 재장전은 5.2초를 유지한다. 양측 센서/ECM·피해·관통·탄속·사거리·포탑/모듈 위치는 바꾸지 않았다. 지구 전함의 지속화력을 소폭 줄이면서 화성의 장거리 정밀성을 조금 낮추는 첫 조정이다.

재장전 시간은 무장 핍·전압·손상·과열이 반영되기 전의 기준값이다. +5% 시간은 같은 출력에서 발사 주기 기준 약 4.8%의 지속화력 감소이며, 첫 발사에는 영향을 주지 않는다. 정확히 10%의 명중률 감소를 보장하는 설정은 아니다. 화성 전함의 관측 위치·예측·속도 오차가 1.1배가 되고, 실제 탄도·함체·실드 충돌로 명중을 판정한다. 전자전·거리·표적 크기·기동과 AI 조준 부위 선택에 따라 실측 명중률은 달라진다.

## 후보 선택

- 기존 단독/호위 조합 비교와 동일한 20/70/130km, 위치 시드·팀 교환·공간 교환·지휘관 규칙을 사용했다. 기준 자료는 `../escort_synergy_20261016/`이다.
- 기준 + 9개 후보를 시드 1~4의 단독·양측 지원 조건에서 각각 96판 시험했다. 지구 재장전 +5/+10%, 화성 재장전 +5%, 화성 오차 +10%, 지구 오차 +5% 및 조합 후보를 구분했다. `candidate-summary.json`에 탈락 후보까지 보존한다.
- 후보는 메모리에서 복제한 함체 정의로만 시험했다. 공유 카탈로그를 바꾸지 않으며, 적용값을 결과 JSON의 `Tuning`에 기록한다.
- 기본 오차 배율 1의 기준 96판은 이전 시험의 승패·함선 통계·피해 사건과 실행시간을 제외하고 전부 일치했다. 새 조정 필드 도입 자체로 전투 결과가 바뀌지 않았다.
- 화성 재장전까지 늦춘 후보는 근거리 단독전의 화성 우세를 더 줄이고 중거리 지구 조합의 전승을 해소하지 못했다. +10% 지구 재장전도 +5%에 비해 일관된 개선을 보이지 않아 작은 조정을 택했다.
- 화성 오차만 +10%인 후보와 최종 조합을 **후보 선택에 쓰지 않은 시드 5~16에서 각각 288판** 추가 검증했다. 최종 조합의 130km 지원전 화성 승수는 예비 14→11/16, 추가 검증 43→39/48로 모두 감소했다. 화성 오차만 늘린 후보는 추가 검증의 130km 단독 화성 승수가 38→43/48로 증가해 덜 적합했다.
- 추가 검증 뒤 수치를 더 조정하지 않고 선택한 값을 실제 JSON에 적용했다. 티어 변형을 재생성했고 T4는 기본값 상속, 지구 T5의 장전 개량은 2.91→3.0555초가 된다. 화성 T4/T5도 오차 배율을 상속한다.

## 결과 해석과 남은 문제

최종 768판에서 다음 결과를 얻었다. 표는 **지구 승 : 화성 승**, 각 칸 64판이다.

| 시작 거리 | 단독 조정 전 | 단독 조정 후 | 양측 호위 2척 조정 전 | 양측 호위 2척 조정 후 |
|---|---:|---:|---:|---:|
| 20km | 16 : 48 | 16 : 48 | 60 : 4 | 61 : 3 |
| 70km | 41 : 23 | 44 : 20 | 64 : 0 | 64 : 0 |
| 130km | 11 : 52, 무1 | 11 : 52, 무1 | 7 : 57 | 14 : 50 |

130km 조합전의 화성 승률은 **89.1%→78.1%**다. 단독전 화성 우세는 유지했고, 20/70km 지구 조합의 우세는 여전히 과도하다. 지구의 센서 상실 후 링크 사격은 70km 양측 지원 조건에서 **634→724발**로 유지된다. 130km 조합전의 지구 무사격은 **8/64척으로 동일**하다. 선택 후보 384판과 실제 적용 후 해당 384판의 함선 통계·승패·사건은 실행시간을 제외하고 완전히 일치했다.

130km 전함 주포 명중률은 단독 화성 84.9%→81.0%, 조합 화성 90.7%→90.4%였다. 지구는 단독 26.4%→21.9%, 조합 38.7%→49.0%다. 재장전·오차 변화가 발사 시점과 피해 경로를 바꾸므로 무기 하나의 고정된 명중 확률로 해석하지 않는다. 장거리 조합 승률 개선이 명중률 10% 감소에서 직접 나왔다는 주장은 하지 않는다.

24척 함대전도 이전 장거리 보고서와 동일 시드·편성으로 24판 재검증했다. 비대칭전은 양팀 각각 전함 1/호위함 6/소형함 5이며 지구 정찰 T3와 화성 강습 T3를 사용한다. 기존 이전 결과를 기준으로 재사용하고, 바뀐 설정으로 새 24판을 실행했다.

| 24척 함대전 | 조정 전 | 조정 후 |
|---|---:|---:|
| 지구 Blue / 화성 Red, 8판 | 지구 5 : 화성 3 | 지구 4 : 화성 4 |
| 화성 Blue / 지구 Red, 8판 | 지구 1 : 화성 7 | 지구 1 : 화성 6 : 무1 |
| 비대칭 합계 16판 | 지구 6 : 화성 10 | 지구 5 : 화성 10 : 무1 |
| 지구 대칭 4판 | Blue 2 : Red 2 | Blue 3 : Red 1 |
| 화성 대칭 4판 | Blue 0 : Red 4 | Blue 0 : Red 4 |

지구 전함의 비대칭전 대응 사격은 **16/16척으로 유지**했다. 큰 함대전에서 승패가 전반적으로 개선됐다고 주장할 근거는 부족하다. 화성 전함의 비대칭 함대전 명중률은 여전히 약 98.5%이고, 팀별 편차도 남는다. 소규모 장거리 조합 편중 완화와 기능 보존을 확인한 작은 조정으로 취급한다.

최종 집계는 `final-comparison.json`과 `final.summary.json`, 함대전은 `fleet-comparison.json`에 보존한다. 각 수치는 같은 시드/편성의 이전 결과와 비교한다. 16개 위치 시드의 팀·공간 교환은 서로 독립적인 64개 시드가 아니다. 후보 탐색에 사용한 시드와 별도 확인 시드를 구분했으나, 이 범위의 결과를 실제 플레이 전체 승률로 일반화하지 않는다. 이번 요청에서 새로 실행한 비교 전투는 2,328판(기준/후보 960, 별도 시드 576, 실제 적용 768, 함대전 24)이며 자동검사 내부 전투는 이 합계에서 제외한다.

- 장거리 호위 조합전의 화성 우세가 완화되면서 전함 단독의 화성 우세와 지구 호위함 데이터링크가 유지되는지 확인한다.
- 중거리 지구 조합의 전승은 재장전 5~10% 조정으로 해소되지 않았다. 첫 일제사격·핵심 모듈 손실·응급복구와 관측 공유가 미치는 영향이 크다.
- 130km 지구 전함의 잠금 상실/무사격은 센서 문턱과 발사 가능 시점의 문제다. 장전·명중 오차 조정으로 해결된 것으로 취급하지 않는다.
- 사격 오차를 늘리면 AI의 작은 부위 조준 가능 판단도 달라질 수 있다. 더 큰 함체 중심으로 조준하는 경우가 있어, 특정 전투의 총 명중률이 반드시 단조 감소하지는 않는다. 피해 기여와 승패를 함께 비교한다.
- 단독/지원 전투는 기존 섬멸전 종료 규칙을 적용하므로 격침되지 않은 함선의 생존시간은 종료 시점에서 중도절단된다. 조합이 빨리 이겼다는 이유로 생존성이 나빠졌다고 판단하지 않는다.

## 구현과 검증

- `RailgunDefinition.AimErrorScale`: 기본값 1, 유한한 양수만 허용. 기존 함체/장비/저장 데이터와 호환된다.
- `FireControl`: 자기 무장의 오차 배율을 아군 링크 관측에도 적용한다. 수신함 센서 상실은 링크를 지우지 않는다. `sensorError:false`의 정확한 탄도 계산은 동일하다.
- 사거리 20/70/130km에서 실제 조준 방향·오차 배율·링크·정확한 탄도·데이터 왕복·잘못된 값 거부 회귀검사를 추가했다. `EscortTrials`에는 후보별 정의 복제, 단독/양측 지원만 빠르게 비교하는 `--primary-only`, 적용값 기록을 추가했다.
- 최종 빌드·전체 검사·기준 보존·모델 보존·확대 전투 결과는 `checks.json`과 로그에 기록한다. 소폭 수치 조정에 따라 전투 통계가 바뀌는 것을 기능 오류로 취급하지 않되, 기존 기능 검사는 그대로 유지한다.
- 전체 **5,607,919개 검사/58개 묶음** 통과(조정 필드 회귀 15개 추가), 측정 fixture 검사 91개 통과. 게임·배치·검사 빌드 오류/경고 0. 시작 시 142개 해시 중 게임 쪽 변경은 기본 전함 JSON 2개, 지구 T5 변형 1개, 사격통제/무장 정의/입력 검증 코드 3개뿐이며 모델·모듈 좌표는 보존했다.

과거 `candidates/` 파일은 변경 당시 기본 함체 위에 적용한 절대값 일부만 기록한다. 현재 기본 함체에는 최종 조정이 적용돼 있으므로 후보를 다시 시험할 때는 양측 재장전/오차 배율을 모두 명시한 `replay-candidates/` 파일을 `--gunnery-tuning`으로 전달한다. 이전 결과를 새 기본값으로 덮어쓰지 않는다. `before-guns.json`에도 변경 전 주포 정의를 보존했다.

원본 전투 JSON은 `.json.gz`, 최종 5초 텔레메트리는 `final.traces.zip`의 조건별 `.csv.gz`로 보존한다. 압축 전후 바이트/CRC를 확인한다. `before-hashes.json`은 시작 시 소스·데이터·모델 142개, `sha256.json`은 최종 측정 코드·자료 해시다. 배포 EXE 갱신과 커밋·푸시는 이번 요청에 포함하지 않았다.
