# 배경 행성: 화면 가장자리에서도 둥글게

2026-10-19. 사용자 질문: 배경 행성이 화면 가장자리로 갈수록 왜곡되는 건 어쩔 수 없나.

## 원인

- 전투 카메라는 세로 시야각 70°(`ChaseCamera.NormalFov`)의 일반 원근(직선) 투영을 쓴다. 16:9에서는 가로로 약 102°를 담는다.
- 직선 투영은 화면 중심에서 θ만큼 떨어진 물체를 바깥 방향으로 약 1/cos θ배 늘린다.
  - 좌우 끝(약 51°)에서 약 1.6배, 모서리(약 55°)에서 약 1.75배, 21:9 화면 끝에서는 2배 이상이다.
- 함선과 별도 같은 비율로 늘어난다. 행성은 둥근 모양이 뚜렷해서 유독 눈에 띈다.

## 대응 (`shaders/gas_giant_disc.gdshader`)

- 시야각을 줄이거나 화면 전체 투영을 바꾸면 조작감과 조준·HUD 계산이 바뀐다. 그래서 배경 행성 하나만 바꿨다.
- 행성을 2×2 사각형(QuadMesh)으로 바꾸고, 셰이더가 화면상의 원판으로 펼친다.
  - **크기:** 행성 중심 방향과 실제 시각 반지름(asin(r/거리))으로 정한다. 화면 중앙에서 보일 크기와 같다.
  - **표면:** 행성을 정면으로 보는 가상 카메라의 광선-구 교차로 픽셀마다 법선을 구한다. 이 법선으로 기존 줄무늬(행성 자전축 포함)와 실제 태양광 음영을 그린다.
  - **깊이:** 행성 중심의 실제 깊이를 쓴다. 앞을 지나가는 함선은 지금처럼 행성을 가린다.
  - **가장자리:** 1픽셀 정도 부드럽게 처리한다(투명 패스). 행성은 가장 먼 물체라 투명 정렬의 맨 앞에 그려진다.
  - **컬링:** 노드의 `CustomAabb`를 실제 행성 크기로 둔다. 중심이 화면 밖이어도 걸친 부분은 그려진다.
- 배치는 그대로다. `ScaleTest.PlaceBackdrop`이 600 km 거리로 당기고 같은 비율로 줄이는 방식이다.
- 표면 무늬 코드는 `shaders/gas_giant_surface.gdshaderinc`로 분리했다.
  - 연출 장면(CineDirector, CinematicTeaser)은 시야각이 46~62°라서 기존 구 메시(`gas_giant.gdshader`)를 그대로 쓴다. 두 셰이더는 이 공통 코드를 쓴다.
- 결과적으로 가장자리 행성은 "화면 중앙에 있을 때의 모습"으로 그려진다. 실제 투영보다 작아 보이지만 크기가 일정해서 자연스럽다.

## 확인

- `before_after.jpg`: 같은 시점(BB-01, `--turn=-25,-12` 가장자리 / `--turn=25,0` 중앙)에서 비교했다.
  - 가장자리: 이전에는 가로로 늘어난 큰 타원이었고, 이후에는 중앙과 같은 크기의 원이다.
  - 중앙: 이전과 같다. 앞 함선의 가림도 유지된다.
  - 원본 전체 화면: `before_edge.jpg`, `after_edge.jpg`, `before_center.jpg`, `after_center.jpg`.
- Godot 검사 통과: `environment-test` 204, `telescope-test` 24, `hud-readability-test` 873, `flow-test` 59.
- 연출 스틸(`cine-still earth 1.0`) 렌더에 셰이더 오류가 없다.
- 시뮬레이션 코드는 바뀌지 않았다.

## 남은 것

- 연출 장면의 행성은 여전히 구 메시라 넓은 시야각 컷에서는 조금 늘어날 수 있다. 필요하면 같은 원판으로 바꿀 수 있다.
