# 영상 v4: 그동안 바뀐 것을 담은 새 구성

2026-10-19. 사용자 요청: 영상을 하나 더 만든다. 변경이 많으니 새로운 구성으로.

- 결과물: `shots/cine/render/project_fleet_v4.mp4`(1920×1080, 30fps, 62초, AAC 음향)
  - 약 105 MB라 저장소에는 넣지 않는다.
  - 다시 만들려면 `.\tools\render-cine.ps1 -Cut v4`를 실행한다.
- 기존 v3 티저(`CineScript`)는 그대로다. 기본 `--cine`은 v3, `--cine-cut=v4`는 이번 구성이다.
- 대표 장면: `frames.jpg`(4, 11, 19, 28, 34, 44, 51, 59초).

## 구성 (`src/Game/Cine/CineScriptV4.cs`)

국면 띠는 편성 · 전개 · 정찰 · 방공 · 강습 · 격침이다.

| # | 장면 | 길이 | 보여 주는 변경 |
|---|---|---|---|
| 1 | 정박지 | 7.5초 | 격납고 미리보기와 같은 궤도 정박지(`HangarPreview.BuildDock` 재사용)에 계류한 T5 전함. 낮은 시점에서 물러난다 |
| 2 | 새 함급 편대 | 8초 | 콘셉트 실루엣으로 다시 만든 지구 T5 함선. 역할별 대열(전함 후열 · 순양함 중열 · 요격 · 정찰 선두) |
| 3 | 머리 위의 적 | 7초 | 머리 위 개전. 뒤집힌 화성 함대가 위에서 다가오고 근접방어가 응사한다 |
| 4 | 정찰 | 9.5초 | 정찰함 프로브가 70 km 밖 적 전위로 날아가 멈추고 전개한다(12배속으로 감음) |
| 5 | 레이저 방공 | 7.5초 | 방공 순양함의 레이저 포대가 미사일 일제사격을 태운다 |
| 6 | 화성 강습 | 8초 | 데이모스 강습 편대가 지구 전함 후미 추진부에 반물질 어뢰를 꽂는다 |
| 7 | 원거리 격침 | 7.5초 | 30 km 밖 호위함 격침의 점광. 게임과 같은 모양의 전과 리본(명중 · 관통 누적)과 "격침" 배너 |
| 8 | 제목 | 7초 | 둥근 가스 행성 위로 PROJECT FLEET |

- 배치와 카메라만 연출하고, 판정은 실제 시뮬레이션이 한다.
  - 시뮬레이션이 맡는 것: 탄도, 미사일, 레이저, 근접방어, 피해, 분해, 프로브 비행.
  - 예외 1: 원거리 격침의 최종 파괴는 정해진 시각에 일으킨다(30 km 탄 비행시간과 무관하게 화면에 맞추려고).
  - 예외 2: 리본과 배너는 연출 시각표대로 그린다.
- 연출상 거리를 줄인 곳
  - 머리 위의 적: 실제 개전은 150 km인데 약 5 km로 줄였다.
  - 새 함급 편대: 대열 간격을 절반 가까이로 좁혔다.

## 추가 기능

- `CineStage.Spawn(callsign, hullId, …)`: T3~T5 변형이나 순양함을 함급 ID로 놓는다.
  - 공장 기본 무장을 합성한다(방공 순양함의 레이저).
- `CineStage.Dock(ship)`, `Props`: 시뮬레이션 좌표에 고정된 소품을 매 프레임 렌더 원점에 맞춘다.
  - 정박지 강판은 전투 조명 아래에서 하얗게 떠서 어둡고 거칠게 바꿨다.
- `CineShot.Banners`, `CineShot.Ribbons`: 게임 `MeritHud`와 같은 모양으로 배너가 열리고 리본이 튀어나온다.
- 연출 행성: 전투 화면과 같은 화면 원판 행성으로 바꿨다. v3에도 적용된다.
- `tools/cine-still.ps1 <장면> <초> [크기] v4`, `tools/render-cine.ps1 -Cut v4`.
- `tools/cine_audio.py`
  - 편집본별 음악 계획(세기 곡선, 북 구간, 상승음, 느린 구간)으로 나눴다.
  - v4 원거리 격침에는 리본 핑과 격침 타격음을 더했다. 30 km 밖 폭발음은 거리 감쇠로 거의 들리지 않기 때문이다.
  - v3는 같은 장면 구조의 합성 사건으로 오디오 경로가 그대로 동작함을 확인했다.

## 조정하며 찾은 것

- 레이저 방공 장면
  - 처음 구성에서는 레이저가 한 번도 쏘지 않았다(포탑 기록 0).
  - 원인 1: 설정 단계에서 "미사일이 7 km 안에 들 때까지 감기"가 방공 순양함 자신의 요격 미사일에 걸려 너무 일찍 끝났다. 이제 적 미사일만 센다.
  - 원인 2: 정면에서 바로 들어오는 미사일에는 포탑 선회가 늦어 추적 중(Traversing) 상태로 끝났다.
  - 그래서 오른쪽 앞 사분면에서 들어오게 하고, 접근하는 동안 포탑을 선두 미사일 쪽으로 미리 돌려 둔다.
  - 같은 조건의 재현 시험에서 펄스가 포탑당 5회에서 14·28회로 늘었다.
  - 참고: 게임 AI에서도 정면 근접 일제사격에는 레이저 포탑이 늦게 따라간다. 균형 검토 후보로 남긴다.
- 머리 위의 적 장면: 해가 +X·+Y·+Z 쪽에 있어 위쪽 함대의 아랫면이 검게 묻혔다.
  - 위쪽 함대를 왼편 위로 옮기고 엔진을 켜서, 햇빛 받는 옆면과 화염이 보이게 했다.
