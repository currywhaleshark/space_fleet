# 교전 접근·강습 유지·AM 준비 AI 수정

2026-10-15 시작, 2026-10-16 검증. 앞선 T3 블록아웃 검증에서 드러난 접근/임무 취소 문제를 수정했다.
**교전 동작 수정이며 진영 균형 달성은 아니다.** 함체 성능, 무기 위력, 센서 공식, 모델 및 모듈 좌표는 변경하지 않았다.

## 수정

- 전함/호위함의 지휘관 대치 거리에도 미잠금 접근 보정을 적용한다. 이전에는 `CommandStandoff`가 있으면 보정이 생략됐다.
- 잠금 없는 먼 표적에 접근할 때 부스트를 사용하고, 목표 속도에도 실제 부스트 배율을 반영한다. 이전에는 부스트 플래그를 켜도 접근 속도 상한은 순항 속도였다. 기존 가속·전력·열·최고속도 제한은 그대로다.
- 전자전 때문에 센서 출력을 올린 경우, 잠금을 얻는 순간 출력을 낮춰 다시 잠금을 잃지 않도록 방해받는 교전 중 ECCM 배분을 유지한다. 기존 사거리 조건·근접 미사일 방어 우선순위·과열 처리는 유지한다.
- 방공 우선 전환은 편대원이 기존 교차 위치 계산으로 실제 요격할 수 있는 미사일에 한정한다. 이미 지나간 미사일을 따라가거나 도달 불가능한 위협 때문에 다른 임무를 취소하지 않는다.
- 출발한 강습 편대는 표적을 유지하며, 아군 기준점의 미사일/요격함 경보 때문에 다시 집결하지 않는다. 출발 전 방공 대응, 명시적 복귀 명령, 과반 편대 손실, 관측 표적 상실, 탄두 소진/위험 또는 강습 가능한 편대원 부재는 여전히 처리한다. 개별 중손상 함은 복귀한다.
- AM 준비는 식별 상태에서 권장 최대 거리+3km 이내(현재 8km)부터 가능하다. 준비 중에는 +5km(현재 10km)를 벗어나거나 식별/전력을 잃으면 취소한다. 8~10km 사이에서 새로 준비하지 않는다.
- 선미 35도 구역은 접근 경로 선정에 남기되, 준비·발사의 절대 조건에서 제거했다. 방어함이 롤하거나 구역 경계가 잠깐 바뀌어도 준비가 초기화되지 않는다. 발사는 계속 **Locked + 권장 최대 5km + 실제 발사각 + 지형/아군 사선**을 요구한다. 발사 후 이탈 중에는 재준비하지 않는다.
- 경량 진단 텔레메트리에 SNR, 관측 함선/거리, ECCM, 부스트, 목표 속도를 추가했다. 전투 판단에는 진단 값을 되먹임하지 않는다.

## 동일 시드 24척 함대전

각 편성 시드 1·2 × 시작 위치 교환, 총 12판. 최대 1,500초, 심우주 섬멸전.
양쪽 전함 1·호위함 6·소형함 5이며 소형함만 T3 전용 형상을 사용한다.
비교 기준은 `../small_hull_combat_20261015/after/*-current.csv`다. 그 원자료는 보존했다.

| 편성 | 이전 → 수정 후 승패 | 평균 종료 시각 | AM 발사/명중 이전 → 이후 |
|---|---|---:|---:|
| 지구 정찰 대칭 | Blue 1/Red 3 → 2/2 | 753.2 → 559.3초 | 0/0 → 0/0 |
| 화성 강습 대칭 | Blue 2/Red 2 → 1/3 | 756.1 → 823.2초 | 0/0 → **24/10** |
| Blue 지구 / Red 화성 | 화성 4승 → 화성 4승 | 833.4 → 746.7초 | 0/0 → 0/0 |

- 화성 대칭전의 강습 개시 평균은 Blue 447.2→390.9초, Red 441.6→450.8초다. 양측 모두 항상 빨라진 것은 아니다. 강습함 격침은 전체 40척 중 9→4척이다. 새 출발 유지와 준비 조건으로 실제 어뢰 공격까지 연결되는 것이 확인됐다.
- 비대칭전 화성의 강습 개시 평균은 621→511초로 앞당겨졌지만, 최종 코드에서는 어뢰 발사 전 표적이 상실되거나 전투가 끝나는 문제가 남았다. 중간 버전 `iteration2`의 2발 발사를 최종 결과로 사용하지 않는다.
- 비대칭전 지구 전함은 여전히 주포 0발이며, 화성 전함은 534발/391명중이다. 지구 센서는 접근 중 먼저 파괴되고 복구 후 다시 손상되는 사례가 있다. 잠금 거리 이전의 장거리 정밀타격·전자전 격차를 다음 균형 조정에서 다뤄야 한다. 데이터링크 기능 고장으로 결론내리지 않는다.
- 지구 정찰함은 자동 강습을 하지 않는 기존 역할을 유지한다. 대칭전 승패 2:2를 균형 달성 근거로 보지 않는다.
- 함종별 피해, 생존(첫 무력화/격침 또는 종료까지 관측), 명중, 프로브/요격 기여, 강습 활동과 잠금 표본은 `summary.json`, `final/*.ships.csv`, `final/*.telemetry.csv.gz`에 있다. 5초 텔레메트리의 관측 횟수는 프레임별 시도 횟수가 아니다.

## 단독 강습 및 형상 재검증

이전과 같은 108조건(2함급 × 2형상 × 방어 3종 × 접근 방향 3종 × 시드 3개).
16km에서 정지 전함에 접근하며, 강한 정상 아군 센서 링크를 제공한다. 전함 주포/미사일/디코이는 끈다.
첫 AM 발사 6초 뒤 명시적 귀환 명령을 내리고 9km 밖 이탈을 측정한다. 완전한 함대 방공망 돌파나 자동 복귀 평가가 아니다.

| 새 형상, PD+드론 | 명중/발사 이전 → 이후 | 이탈 이전 → 이후 | 유폭 이전 → 이후 |
|---|---:|---:|---:|
| 알타이르 | 5/9 → 7/9 | 9/9 → 9/9 | 0 → 0 |
| 데이모스 | 5/9 → 4/9 | 7/9 → 8/9 | 2 → 1 |

무방어/PD만 있는 조건은 두 형상·두 함급 모두 각각 9발 발사·9명중·9이탈이다.
평균 첫 발사 시각은 알타이르 41.8→36.6초, 새 데이모스 51.1→55.5초다.
일찍 준비하도록 바꾸면 유도 조준·비행 궤적과 방어 드론의 교전 시점도 달라지므로 모든 조건의 발사/명중률이 단조 증가하지 않는다.

피탄 투영·내부 관통·PD 가시성 JSON은 이전 측정과 **완전히 동일**하다. 블록아웃 해시 목록 전체도 일치한다.
데이모스의 정면 노출과 이탈 중 격리실 위험은 남지만, 작은 생존 표본만 보고 격리실 HP나 외형을 축소하지 않았다.
이번에는 AI 원인을 분리했으며, 모델 변경은 이후 노출 방향별 반복 측정에 근거해 진행한다.

## 검사·재현

신규 회귀 검사 `--engagement`는 접근/실제 부스트 요청, 관측되지 않은 위치 변경 무시, ECCM 잠금 유지,
도달 가능한 방공과 지나간 미사일 구분, 강습 유지/복귀/손실/탄두 소진/표적 소실, AM 준비 히스테리시스·잠금·사거리·이탈을 검사한다.
전체 검사 출력은 `simchecks.log`, 게임 빌드는 `game-build.log`다. 새 배포 실행파일·커밋·푸시는 만들지 않았다.
전체 기능 **5,607,690개(신규 33개)** 통과, 게임 및 검사 도구 빌드 경고/오류 0.
기존 난전 빈도 검사도 이번 코드에서는 시드 1~6 모두 난전 조건을 충족했다(6/6). 다른 편성 전체의 균형을 뜻하지 않는다.
이전 블록아웃 해시 48개 전부 일치했고, 모델은 바꾸지 않아 이번에 렌더 검사를 반복하지 않았다.
여러 검사를 병렬로 실행했으므로 wall time은 단독 FPS/틱 성능 측정으로 해석하지 않는다.

# 지구 대칭: Earth/Earth, earth_recon_t3/earth_recon_t3
# 비대칭: Earth/Mars, earth_recon_t3/mars_assault_t3
