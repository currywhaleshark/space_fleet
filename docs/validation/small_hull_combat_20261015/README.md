# T3 알타이르·데이모스 형상 전투 검증

2026-10-15. 새 블록아웃의 피탄 면적·내부 관통·PD 사각·강습과 이탈을 측정했다.
이번에 수정한 게임 동작은 **PD가 자기 선체를 관통해 미사일과 요격함을 쏘던 판정**이다.
모델·장비 좌표·성능 수치는 그대로 유지했다. 밸런스 완료 판정은 아니다.

## 비교 조건

- `legacy`: T3의 현재 성능을 유지하면서 해당 진영 기본 요격함의 구획·모듈·발사구·PD 위치를 복원한 측정용 정의.
- `current`: 현재 T3 전용 블록아웃 정의. 기하에서 파생되는 충돌체와 실드 외형도 함께 달라진다.
- 레이 측정은 게임의 구획 AABB 판정을 쓴다. 렌더 메시의 정확한 경사면 면적이 아니다.
- `before/`는 PD 차폐 수정 전, `after/`는 수정 후 원자료다. 형상끼리의 함대전 비교는 모두 수정 후 규칙을 사용한다.
- 함대 비교용 복제 초기화는 수정 전 정규 생성 경로와 시드 1 정상/교환의 전투 요약이 완전히 같음을 확인했다(`before/clone-check.log`). 글로벌 함체 레지스트리는 바꾸지 않는다.

## 피탄 면적과 관통

44×44m 평면의 0.5m 격자에서 수직으로 발사해 실제 선체에 닿는 면적을 합산했다. 각 레이는 새 함체와 새 탄약 상태로 시작한다.

| 방향 / 면적(m²) | 알타이르 기존 → 새 형상 | 데이모스 기존 → 새 형상 |
|---|---:|---:|
| 정면·후면 | 30.5 → 42.5 (+39%) | 19.0 → 43.0 (+126%) |
| 측면 | 92.0 → 96.0 (+4%) | 71.25 → 89.0 (+25%) |
| 상면·하면 | 291.0 → 176.0 (-40%) | 166.0 → 139.0 (-16%) |
| 후방 하부 사선 | 151.0 → 113.0 (-25%) | 87.5 → 95.0 (+9%) |

상면이 좁아졌다는 사실만으로 작은 표적이 되었다고 볼 수 없다. 특히 데이모스는 넓은 엔진 포드, 큰 격리실과 꼬리 구조로 정면 노출이 늘었다. 추후 외형 수정에서 이 부분을 우선 검토한다.

- 실드를 제외한 직접 선체 사격: PD 기준 20 에너지/25mm 관통/모듈 피해 10, 레일 기준 220/250mm/120. 정상 HP에서 시작하며 PD는 ARMING 상태로 측정했다.
- 한 발의 PD로 즉시 유폭한 레이는 모든 조건에서 0개다. 이 결과가 연속 피격·손상된 격리실의 안전을 뜻하지는 않는다.
- 새 데이모스 정면에서 AM에 도달한 레일 사격 면적은 1→4m², 측면은 2.5→6m²다. 격리실의 실제 부피 확대에 따른 노출이다.
- 새 두 함체 모두 후면에서 AM과 반응로가 같은 관통선으로 손상되는 면적이 각각 0.5m² 남는다. 공간상 분리와 관통 경로 분리는 다르다. 정면·측면·상하·후하 사선에서는 동시 손상 0m²다.
- 전체 방향과 모듈 피격 면적은 `after/projection.json`에 기록한다. 0.5m 표본이 놓치는 얇은 영역은 있을 수 있다.

## PD 차폐 오류 수정

기존 PD는 드론·프로브를 상대할 때 자기 선체를 포함한 사선 검사를 했지만, 미사일·요격함에는 지형과 기계적 사격각만 검사했다. 따라서 회전각 안에 있는 꼬리날개·엔진·갑판을 관통해 쏠 수 있었다.

- 모든 표적 종류에 자기 선체 차폐를 적용한다. 갑판 경계와의 오차를 피하기 위해 포탑 피벗에서 로컬 갑판 바깥으로 5cm 이동한 지점을 사용한다.
- 표적 후보가 기존 우선순위를 이길 때만 추가 레이를 검사한다. 미사일·요격함을 위해 전체 함선 순회를 새로 추가하지 않는다.
- 기존 PD 회전 속도·상하각·방위각·사거리·위력은 유지한다. 드론·프로브의 다른 함체/잔해 차폐 검사도 유지한다.
- 재현: 실제 T3 꼬리날개 뒤의 정지 요격함을 향해 발사하던 기존 코드는 신규 검사에서 실패했다. 수정 후 두 T3의 미사일/요격함 2종, 원점/1e12m 회전 배치에서 차폐 중 정지 → 열린 후방에서 사격 → 재차 차폐되면 즉시 정지가 통과했다.
- 기존 지형 검사에서 목표가 전함 선수 아래에 있어 자기 갑판에도 가려지던 조건은 목표를 위로 300m 옮겼다. 지형 차폐의 성공/실패 기대값은 유지했다. 비최적화 참조 방공 루프에도 같은 새 규칙을 적용한 뒤 공간 탐색 동등성을 검사했다.

800m 거리의 구면 2,048방향을 표본으로 계산한 **기계 각도 + 자기 선체 차폐 이후의 가시 방향 비율**:

| 함급 | 기존 형상 | 새 형상 | 새 형상의 기계각 내 차폐 방향 |
|---|---:|---:|---:|
| 알타이르 | 54.9% | 50.1% | 96/2,048 |
| 데이모스 | 28.1% | 23.9% | 121/2,048 |

알타이르의 상·하부 포대는 후방을 함께 맡고, 데이모스의 상부 1기는 후하방 사각을 유지한다. 매몰된 피벗은 0개다. 이 표는 명중률이나 순간 대응력을 뜻하지 않으며 실제 회전 시간·표적 속도·센서·전력은 별도로 작용한다(`after/coverage.json`).

## 단독 강습·이탈 108조건

2함급 × 2형상 × 3방어 조건 × 3초기 접근 방향 × 시드 1~3.
16km에서 전방/상방/후하방으로 시작해 기존 침투 AI가 경로를 선택한다. 아군 센서 기준점이 정상 관측을 제공한다. 적은 정지한 지구 전함 1척이며 주포·미사일·디코이는 없다. PD/드론만 조건별 활성화한다. 이 검사는 완전한 적 함대 돌파 시험이 아니다.

첫 어뢰 발사 6초 뒤 출발 방향의 14km 지점으로 **명시적 복귀 명령**을 내린다. 9km 밖으로 나가면 이탈로 기록한다. 편대의 자동 복귀 판단을 검증한 결과로 해석하지 않는다. 알타이르도 여기서는 직접 강습 명령을 받는다.

| 방어 / 형상 | 알타이르 AM 명중·발사 / 이탈 | 데이모스 AM 명중·발사 / 이탈 |
|---|---:|---:|
| 무방어 / 기존·새 형상 각각 | 9/9 · 9/9 | 9/9 · 9/9 |
| PD / 기존·새 형상 각각 | 9/9 · 9/9 | 9/9 · 9/9 |
| PD+드론 / 기존 형상 | 5/9 · 9/9 | 6/9 · 9/9 |
| PD+드론 / 새 형상 | 5/9 · 9/9 | 5/9 · 7/9 |

- 새 형상의 PD+드론 조건에서 두 함급 모두 나머지 어뢰 4발은 드론에 요격됐다. PD만으로 어뢰를 요격한 경우는 없었다. AI가 후하방 침투 경로를 택하는 조건이며 PD의 전 방향 성능으로 일반화하지 않는다.
- 새 데이모스의 손실 2건은 상방 출발 시드 2/3, 발사 후 약 19.5초의 이탈 중 **AM 격리 실패**다. 어뢰를 이미 한 발 쓴 뒤에도 남은 탄두의 탑재 위험이 작동한다. 이 두 건을 단순 선체 HP 부족으로 해석하지 않는다.
- 발사 평균 시각: 알타이르 41.8초, 데이모스 51.1초. 이탈 성공 시 발사 이후 평균: 알타이르 53.6초, 새 데이모스 PD+드론 조건 25.2초. 경로와 초기 방향이 섞인 평균이며 두 함급의 순수 속도 비교가 아니다.
- `after/assault.json`은 격침 원인, AM 유폭 횟수, 비행 종료 원인도 기록한다. `before/assault.json`은 공통 결과 필드만 가진 수정 전 기록이다.

## 24척 함대전 24판

각 형상에서 지구 정찰 대칭 / 화성 강습 대칭 / 지구 정찰 대 화성 강습을 시드 1·2와 시작 위치 교환으로 4판씩 실행했다. 편성은 각 팀 전함 1·호위함 6·소형함 5. 양측 소형함 5척만 T3 갈래로 교체하고 중·대형은 기존 함체를 쓴다. 최대 1,500초, 섬멸전 규칙이다.

| 편성 | 기존 형상 결과 | 새 형상 결과 | 평균 종료 시각 기존 → 새 |
|---|---|---|---:|
| 지구 정찰 대칭 | Blue 4승 | Blue 1 / Red 3승 | 756.6 → 753.2초 |
| 화성 강습 대칭 | Blue 2 / Red 2승 | Blue 2 / Red 2승 | 583.2 → 756.1초 |
| Blue 지구 / Red 화성 | 화성 4승 | 화성 4승 | 791.4 → 833.4초 |

모든 판이 전력 상실 판정으로 종료했다. 동일 진영에서도 표본별 승패가 바뀌므로 소수 시드의 승률을 균형 달성으로 해석하지 않는다. **화성 우세는 형상 변경으로 해결되지 않았다.**

- 24판 전체 AM 발사 0회. 새 비대칭전에서는 화성 강습 시작 평균 621초, 5초 간격의 살아 있는 편대원 관측 중 강습 상태의 행동은 위치 유지·외곽 우회가 대부분이다. 일부만 사거리 근처에 도달했다. 개별 어뢰는 단독 시험에서 정상 동작하므로 편대 강습 기회·집결·경로·목표 잠금 과정을 따로 조정해야 한다.
- 새 비대칭전의 지구 정찰함은 총 80개 프로브를 전개, 신규 접촉 기여 9건, 자동 강습·어뢰 발사 0회. 정찰 임무는 유지된다.
- 같은 비대칭전 지구 전함은 주포 발사 0회. 활성 관측 표본 274개에서 현재 목표 Locked 0개다. 화성 전함은 494발 중 378발 명중. 지구 접근/잠금 격차가 여전히 크다.
- 새 화성 대칭전: 소형함 40척 중 9척 격침, AM 격리 실패 5회. 기존 형상은 7척 격침·격리 실패 3회. 이 수치만으로 한 형상의 생존력이 우월하다고 판단하지 않는다(교전 경로·종료 시각·승패도 달라짐).
- 아군 충돌은 기존 형상 12판 합계 5회, 새 형상 12판 합계 5회다. 모두 충돌 없음으로 처리하지 않는다.
- 함종별 피해 기여·생존(첫 무력화/격침 또는 종료까지 관측)·사거리·명중·프로브·요격·어뢰는 `*.ships.csv`와 `summary.json`; 5초 상태 관측은 `*.telemetry.csv.gz`에 보존한다. 원시 텔레메트리는 손실 없이 압축했다.

```powershell
python tools/analyze-small-hull-trials.py docs/validation/small_hull_combat_20261015
```

`--small-geometry`는 측정 도구 전용이며 정규 24척·심우주·섬멸전에만 허용된다. 기본 게임 함체를 되돌리지 않는다. `before/` 재현에는 PD 차폐 수정 전 코드가 필요하다.

다음 조정 우선순위: 지구의 교전 잠금·접근 → 화성 강습 편대의 사거리 도달 → 데이모스 정면 노출과 이탈 중 격리실 피격 → 다시 균형 측정 → 외장 마감. 새 EXE/커밋/푸시는 만들지 않았다.
