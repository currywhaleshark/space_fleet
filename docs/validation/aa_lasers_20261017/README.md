# 방공순양함 기본 레이저 검증 — 2026-10-17

T3 시러스·T4 스트라투스·T5 님버스의 기본 주포를 레이저로 합성하고, 주포가 관측 미사일을 포탑별로 나눠 요격한다. 기존 함체·모듈/Blender/GLB·PD/요격 미사일/드론을 보존했다. `defaultMainGun`이 없는 함급에는 기본 무장 변경이 없다.

## 역할 비교

`dotnet run --project tests/SimChecks -c Release -- --aa-lasers`

`waves.json`에 64개 실행을 기록했다. 시드 1~4의 동일 위치 배열과 같은 AI를 레일건·레이저에 각각 적용했다. 보호 대상은 정지·무장 없는 전함, 방공순양함은 전방 5km에서 위치 유지. 일반 호위함 미사일(체력 12)을 실제로 발사한 뒤 정해진 종말 접근 위치와 속도로 배치한다. 추진 종료 이후의 관성 접근이며 발사대의 탄약만 시험을 위해 보충한다. 방어함의 탄약·열·선회·피해는 보충하거나 늘리지 않는다. 각 실행 25초, 각 미사일은 실제 충돌·명중/요격 경로를 사용한다.

각 행은 같은 조건 4회 합산이다. 정상 공세는 두 포탑이 서로 다른 표적을 실제 배정받았으며, 레이저는 탄체/탄약 소모 없이 물리 광선으로 격추했다. 고속 포화공격은 대부분 관통했다. 이 결과는 통제된 역할 시험이지 혼성 함대전 승률·모든 접근각·ECM 상황의 확정 밸런스가 아니다.

## 동작 검사

- 기본 무료 장착, 기존 프리셋 저장/로드, 연구한 레일건으로 교체, 다른 부품 교체 시 기본 레이저 보존.
- 미사일 두 개를 상/하 포탑에 분배. 비관측 실제 좌표 이동이 사격 해에 영향을 주지 않음. 미탐지/소실 표적의 사격 금지.
- 수동/집중/정지 우선, 지형/아군 사선 보류, 근접 횡단 시 유한 선회속도, 열 85% 자동 중단 및 기존 냉각 히스테리시스.
- `aa-lasers.log`: 신규 33개 검사와 역할 시험. 전체 회귀검사는 `sim-all.log`.
- `models.log`: 실제 Vulkan 렌더에서 10,420개 모델 검사. 기본 레이저의 포탑/고각/포구·애니메이션 확인. MultiMesh 검사가 있는 모델 검증은 headless 렌더를 사용하지 않는다.
- `portraits.log`: 기본 레이저가 반영된 3종 카드 초상화. `hangar.png`: 실제 격납고 렌더.

전체 240척 렌더 FPS, 장기 혼성전 승률 및 플레이어 실전 난이도는 이 시험에서 확정하지 않았다. 수치는 후속 플레이와 함대전 통계로 조정한다.

전체 시뮬레이션 회귀검사 63묶음, 5,671,770개 통과(프로세스 종료 코드 0). 기본 무장이 바뀐 함급의 레거시 스키마/재장전 가정은 레이저 스키마·초당 에너지 검사로 갱신했다.

기본 레이저 3종도 큰 double 좌표의 포탑/포구·발사·발열·집중 동등성 검사를 그대로 수행하도록 확장했다. 최종 `hardpoints-final.log`의 67,844개 검사 통과. 이 추가 검사는 전체 회귀검사 이후 실행했으며 시뮬레이션 제품 코드는 바뀌지 않았다.
