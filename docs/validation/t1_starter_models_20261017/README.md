# T1 제피르·루나에 독립 기본형 — 2026-10-17

기존 T1은 전용 파일이 있으나 T2 호위함을 80%로 줄인 모델이었다. 사용자의 T1 추가 지시에 따라 이미지 참고 → 별도 Blender 기본형 → 실제 게임 연결로 다시 제작했다. 전체 모델 수는 24개로 같으며, 이번에는 그중 T1 두 파일의 형태를 교체했다. 남은 공유 모델은 T5 10함급이다.

| 함급 | 기본형 | 주포 / 미사일 / PD | 삼각형 / 렌더 메시 |
|---|---|---|---|
| 제피르 `earth_starter_escort` | 둔한 장갑 선수, 낮은 함교, 수평 방열판 | 연장 1기 / 12발 / 4기 | 9,420 / 11 |
| 루나에 `mars_starter_escort` | 가는 선수, 외부 센서, 노출 기관 구획과 수직 방열판 | 연장 1기 / 12발 / 2기 | 9,456 / 7 |

두 함의 주포 피벗·포구·탄약 480발, 소형 Sensor/ECM 베이 1개, 기존 무장·방어·기동·센서·AI 수치와 모듈 크기를 유지했다. 센서·방열판 중심 및 제피르의 후방 PD 위치와 외피 구획은 새 형상에 맞췄다. 삭제된 하부 주포의 잔여 외피 구획도 루나에에서 제거했다. 실드 표면 장비는 내부 모듈과 같은 앞뒤/좌우 위치에 있다.

## 보존과 생성

- `baseline.json`과 `art/archive/20261017_t1_scaled_originals/`: 기존 T1 원본/GLB/이미지/variant 8개와 전체 manifest를 복사해 보관했다. 해시 일치 확인. 다른 22모델과 다른 함급/연구 데이터 보존.
- `data/model_layouts/<ID>.json`: 새 외피와 모듈 좌표의 기준. `tools/author-t1-starter-layouts.py`는 기존 성능에서 형상만 분리한다.
- `tools/build-t1-starter-models.py`: 184/187개 편집 부품, 회전·고각 리그, 포구·PD·엔진·RCS 마커, 숨긴 모듈 피해 가이드. GLB는 고정 외피를 병합하고 움직이는 포탑만 나눈다.
- `tools/generate-progression-data.py`: 독립 T1은 기존 T1 성능을 유지하며 배치를 적용한다. 재생성 검사에서 예전 방식이 현재 T2 센서/PIP를 덮어쓰는 차이를 찾아 수정했다. 이번 활성 T1 성능 수치는 바뀌지 않았다.
- `tools/build-starter-models.py`: 새 배치가 있는 경우 예전 축소 방식의 덮어쓰기를 거부한다. 수동 편집 이후에는 `tools/export-ship-models.py`를 사용한다.

## 검증

- `preservation-audit.json`: 기존 파일 101개 해시 보존, 보관 원본 9개 해시 일치, T1 성능/장갑 두께 보존, 34함급과 연구 트리 재생성 일치.
- `geometry-audit.json`: 85개 모듈·포구·베이·PD·엔진·RCS 좌표, 최대 오차 0.000008m 미만. 두 함 모두 부품 연결 그룹 1개, 추진구 4개 후방 가시성 통과. 미사일 발사구를 막던 받침 상단을 낮추고 열린 발사구 검사 추가.
- `sim-progression.log`: 558개 통과. 두 함 전체 모듈 35개의 회전한 대규모 double 좌표에서 실제 관통, 연장포 두 탄의 포구/소모, 미사일 사출/독립 탄약, 연구·저장·매칭·출격 포함.
- `dotnet-build.log`: 경고 0 / 오류 0.
- `*_hero/underside/top/rear.png`: 최종 Blender 검토 렌더. 연결 검사는 AABB 기반 후보 검출이므로 상·하·후방 육안 검토로 보완한다.
- `*-hangar.png`: 실제 1600×900 Godot 격납고. 캡처는 `shots/t1-starter-model-user`로 사용자 저장을 분리한다.
- 격납고 검수에서 배열 인수를 문자열로 넘겨 첫 함만 갱신하던 초상화 도구 문제를 발견했다. `export-menu-art.ps1`은 쉼표 문자열/배열을 모두 정규화하고 요청한 모든 함의 출력 로그를 검사한다. `portraits.log`와 이전 이미지 대비 해시로 T1 두 이미지의 갱신을 확인한다.
- 배포 이름 `SpaceFleet-20261017-t1-starters-v2-Windows-x64`. `release-verification.json`: 실제 EXE 15묶음/7,938개(모델 6,664개) 통과, ZIP CRC·SHA-256과 최종 ExportRelease DLL 일치. 두 T1 초상화 출력 및 이전 이미지 대비 변경도 확인했다. 이동할 때는 ZIP 전체를 풀어 실행한다.

전 함급의 세부 외장은 아직 보류한다. 이번 모델 변경의 장기 승률 및 240척 FPS는 측정하지 않았다.
