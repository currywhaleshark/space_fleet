# Menu artwork

`ships/*.png` are transparent stock-hull portraits rendered from the game's existing GLBs through `ShipView`. `MenuArt` resolves them by `ShipDefinition.ModelId`, so variants sharing a model share a portrait. The large hangar preview still renders the fitted ship, including primary-weapon changes.

After changing a model, build `SpaceFleet.csproj` and run `tools/export-menu-art.ps1` from the repository root. The exporter uses one temporary viewport at a time, crops transparent margins, then imports the PNGs. Ordinary menus only load and cache the resulting textures; no additional live 3D viewport is created per card.

`equipment/*.svg` are original equipment schematics generated by `python tools/build-menu-icons.py`. These indicate equipment categories and gun barrel arrangements, not promised final 3D hardware. Names and resolved-fit tooltips carry the exact selection and effects.
