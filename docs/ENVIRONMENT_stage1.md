## 4차 — 관측 차폐와 60초 전술 추적 기억

- `SensorNet`/`SmallContactSensors`에서 관측함·프로브별 시선을 검사한다. 다른 각도의 관측과 아군 데이터링크는 유지하며, 화성 호위 재머도 각 관측자까지의 시선으로 계산한다. 미사일·프로브의 소형 접촉은 차폐 직후 유효성을 잃는다.
- `SensorMemory`는 마지막 관측 위치·속도·시각만 저장하는 별도 질의다. 차폐 때문에 접촉을 잃은 경우에만 생성하고, 60초 만료 또는 재획득 시 제거한다. 거리·신호만으로 소실된 접촉에는 생성하지 않는다. 오차 증가율은 `max(100m/s, 마지막 속력 × 0.5)`를 사용했다. 느린 주력함도 60초 뒤 최소 6km, 고속 요격함은 더 큰 오차를 갖는다. 보장된 도달 영역이 아닌 속도 불확실도 근사다.
- `SimAI`, 편대/화성 교리와 점령 명령은 기억된 표적을 유지하되 사격·반물질 준비는 중단한다. 점령 편대는 거점 대기점을 계속 지킨다. 구조물이 있는 전장에서 적 회피도 관측값/예측값을 사용한다. 숨은 실제 위치·속도·격침 여부가 기억 추적에 영향을 주지 않는 검사를 포함했다.
- `BattleLog.SensorOcclusion`과 별도 환경 CSV에 진영별 잠금 소실 횟수·시간·재획득을 기록한다. 시간은 여러 표적을 합산한 **표적·초**로, 전투 경과 시간을 초과할 수 있다.

## 5차 — 무기·프로브 차폐

- `SimBallistics`는 장애물 첫 교차를 같은 240Hz 구간의 함선·소형 표적·드론 충돌과 비교한다. 먼저 닿은 물체만 처리한다. 자동 주포는 각 포구→예측점이 막히면 `Obstructed`(지형 가림), 수동 주포는 실제로 발사되어 구조물에서 소멸한다.
- `SimMissiles`, `CounterMissiles`, `Antimatter`는 공통 선분 충돌을 사용한다. 일반·경량·AM의 함선 직접 충돌과 구조물 충돌 순서를 비교한다. AM의 장애물 충돌은 별도 결과로 기록하고, 기존 순간 섬광을 사용한다. 구조물에 맞은 폭발은 뒤쪽 함선으로 피해를 전달하지 않는다. 탐색기 시선도 가리며 우회 유도는 추가하지 않았다.
- `DroneCombat.ClearDefenseLine`와 PD 후보 광선에 차폐를 적용했다. 근접신관이 벽 반대편의 미사일에 피해를 주는 경로도 차단했다. AI의 미사일/AM 발사는 막힌 방향에서 보류한다.
- `ReconProbes`는 투사 목적지가 구조물 안이면 사출 방향의 앞 표면으로 옮기고, 이동 선분이 충돌하면 소멸한다. 전개 도중 마주치는 장애물을 우회하지 않는다. 기존 무기/센서 데이터는 수정하지 않았다.
- 신규 무기/프로브 검사 82개: 실제 수동 발사, 동시 하위 틱의 첫 충돌, 세 미사일 계열, 원거리 좌표, 공유 잠금 아래 자동 발사 보류, 실제 PD/드론의 차폐·개방 사격, 프로브 표면 정지·고속 충돌.
