# 교체 주포·부포 전투 검증 — 2026-10-16

교체 무장의 실탄·피해·탄약·열 연결을 확인했고, **부포의 대요격함 피해 배율 누락과 5km 피해 판정 제한을 수정했다.** 장비 수치 자체는 바꾸지 않았다. 기능 통과와 최종 밸런스 확정은 구분한다.

## 수정 사항

- 이전 `EngagePointDefense`는 미사일·드론·프로브에는 `DamagePerHit`을 사용하지만, 요격함에는 고정 `DamagePacket(20,25,10,5000)`을 사용했다. 따라서 탄막형 피해 -10%, 원거리형 피해 +15%가 함선 표적에 적용되지 않았다.
- 원거리 부포는 전함·호위함에서 사거리가 4,500→5,175m로 늘어났지만, 실제 대함 피해 광선은 5,000m에서 끝났다. 5,040m 노출에서 발수는 기록되고 함선 피해는 0인 경우를 재현했다.
- `PointDefenseDefinition.ShipPacket`에 대함 피해를 선택적으로 저장한다. 교체 부포에만 기존 대함 에너지/모듈 피해 × 배율과 교체 사거리를 넣는다. 성공한 PD 명중과 착탄 효과의 에너지도 같은 값을 쓴다. 관통력은 유지한다.
- 기본 부포의 null 값은 기존 패킷으로 해석하고 JSON에서는 생략한다. 기본 34함급의 정의·LoadoutId, 기존 회귀 출력은 변경 전과 같다. 매 틱 부품 카탈로그를 검색하지 않는다.
- 실제 요격함 실드 피격에서 기본/탄막/원거리의 발당 에너지가 **20/18/23**임을 확인했다. 교체 사거리보다 짧거나 음수 피해인 명시적 패킷은 데이터 검사에서 거부한다.

## 시험 구성과 원자료

`tools/BattleBatch/ComponentTrials.cs`는 게임에서 호출되지 않는 측정용 진입점이다. 매 측정에 독립 월드를 만들고, 아래 통제 시험과 자율 전투를 분리한다. 원자료를 요약한 전체 표는 [measurements.md](measurements.md), 검증 및 소스/원자료 해시는 [verification.json](verification.json)에 있다.

- **bench.json — 72조건.** 기존 6함체 × 기본/호환 주포 2형식. 모든 포탑이 사격 가능한 방향으로 정렬한 뒤 300초 연속 사격(기본 2PIP와 무장 4PIP), 실제 포탑 하나/고정포의 5km 실드 시험, 실드 제외 모듈 중심 관통 경로 1,905개. 실드 시험은 실제 탄체·실드 재생을 유지하고 180초까지만 진행한다. 장갑 시험만 각 광선 전에 표적을 복구하며, 한 포탑 일제 피해 표는 독립된 발당 피해 × 포신 수의 환산이다. 실제 일제에서 같은 모듈을 연속 파괴한 결과는 아니다.
- **duels.json — AI 144판, 최대 300초.** 6함체 × 3형식 × 시드1·2 × 장착 진영 교환 × 2거리. 전함 20/100km, 호위함 6/40km, 요격함 3/15km. 같은 함급의 기본형과 교전한다. 각 팀의 이름·초기 위치·방향·함선/AI 갱신 순서를 고정하고 장착 팀을 바꾼다. 기본 대 기본은 두 실행의 결과가 완전히 같은지 별도 검사한다. 실제 센서·AI·회피·미사일·어뢰·PD·드론·손상·복구를 사용하며 체력/탄약 리셋과 강제 조준은 없다.
- **pd-legacy.json / pd-fixed.json — 각각 432조건.** 6함체 × 3형식 × 시드1~4 × 요격함/경량 미사일 × 3노출(500m 정지, 500m 최근접·1,200m/s 횡단, 기본 사거리의112% 정지). 첫 PD 마운트 법선을 중심으로 노출하고 실제 전체 PD 포대·포각·선회·가림을 유지한다. 드론은 제외한다. 함선 표적만 매 틱 복구하여 사격 시간과 발당 피해를 분리한다. 미사일은 실제 탄체/내구도이며 추진·유도를 멈추고 정해진 경로에 놓는다. **유도 미사일의 자연 비행을 재현한 침투율 시험은 아니다.** 시드는 대상 ID/호출명에 의한 명중 난수를 바꾼다. `--legacy-pd`는 교체 패킷만 제거해 옛 고정 피해 경로를 재현하는 대조군이며 과거 실행 파일의 스냅샷은 아니다. 변경된 90조건은 모두 교체 부포의 대함 피해이고, 기본 부포와 모든 대미사일 조건은 전후 동일하다.
- **fleet.json — 혼성 10:10 편대 6판, 최대 300초.** 시드1에서 지구 전함 편대 80척 전장, 화성 요격 편대 88척 전장. 플레이어 소유 편대의 해당 함급만 기본/교체2형식으로 바꾸고 모두 AI로 운용한다. 3연장포와 두 고정포 모두 실제 전투에서 발사했다. 주변 AI는 기존 기본 계통/장비 선택을 유지한다. 대표 2함급의 기능 시험이며 모든 교체 계통 조합이나 장기 승률 검증이 아니다.

## 남은 관찰 사항

1. 탄막형은 경량 미사일의 필요한 명중 횟수가 증가하는 문제부터 다룬다. 발당 피해·연사·대상별 역할 중 어느 것을 바꿀지 추가 비교할 수 있다. 이번 수정은 빠졌던 대함 피해 배율만 연결했으며, 미사일 피해 수치는 이전과 같다.
2. 단장포는 발당 효과가 분명하지만 이 시료의 동종함전에서는 일제 화력 손해가 자주 크게 나타났다. 지원함이 실드를 벗기는 혼성팀 조건과 장갑이 두꺼운 경로에서 역할을 검증한 뒤 조정한다. 4판짜리 조건별 결과로 승률을 확정하지 않는다.
3. 혼성 80척의 기본 지구 전함은 주포 0발로 293.57초에 격침됐다(미사일은 9발 발사). 단장/3연장은 각각 5/9발 발사했다. 시작 직후 격침 사례는 아니지만 기존 교전/조준 AI의 무사격 문제를 별도 추적할 근거다. 이 한 판으로 교체 무장의 생존 보너스를 주장하지 않는다.
4. 단독 요격함 15km 조건은 기본/교체 모두 300초 동안 미교전이었다. 3km 조건과 혼성전의 실제 사격과 구분한다. 이 24판을 새 무장 유효 성능의 증거로 세지 않는다.
5. 화성 호위함 첫 하부 포대의 법선은 수직 하향이다. 해당 정지 노출은 고각 90°로, 기존 최대85° 밖이어서 모든 형식에서 발사0이다. 횡단할 때에는 교전했다. 교체형 오류로 해석해 기계적 사각을 없애지 않았다. 작은 요격함 PD도 빠른 횡단 표적에는 1~2발만 발사했으며, 기존 선회 제한이 유지된다.
6. 전력/냉각 조합에 따른 전체 밸런스, 다른 티어 함급, 완주 승률과 실제 플레이 조작감은 이번 대표 무장 검증 범위 밖이다. CPU 병렬 측정을 사용했으므로 결과에서 성능 향상이나 FPS를 주장하지 않는다. 외형·입력은 앞선 `components_20261016`의 렌더 검사에 근거하며 이번에 새로 촬영하지 않았다.

## 회귀 검사와 재현

전체 SimChecks **61묶음 / 5,677,061개** 통과. 교체 계통 검사는 1,893개이며 기본 정의/세팅 ID 34개와 기존 회귀 출력은 앞선 `components_20261016` 자료와 동일하다. 게임·BattleBatch·ScaleBench 빌드 성공. 게임 빌드의 경고4개는 네트워크에서 NuGet 취약점 정보를 조회하지 못한 `NU1900`이며 컴파일 오류는0이다. 다른 두 빌드 경고/오류0. 배포 EXE 갱신과 커밋/푸시는 하지 않았다.
